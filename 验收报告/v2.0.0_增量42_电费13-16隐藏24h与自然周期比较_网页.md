## 1. 改动

### 1.1 13/16 号楼隐藏 24h 趋势
- 楼栋级判定（`PW_SLOW_BLD`，`slowBldOf`），与「网关是否提速」的数据判定 `isSlowRoom` 分开；
- `renderChips` 对 13/16 号楼隐藏 24h 按钮（`hidden` + `display:none`）；
- 选中这类宿舍时若当前档位是 24h → 自动落到 7 天（`normRangeForSel`，只在切换宿舍/进入页面时归位，不覆盖用户显式选择）；
- 切回实时房时恢复进入慢楼栋前的档位（用户手选过 7d/30d 则保留）；
- 24h 数据仍按原契约拉取（慢频房 3 窗口），仅用于「日更」检测/估算/无更新提示；趋势图不再展示 24h；
- `setRange` 保留程序化切 24h 的入口（测试/深链用），鼠标无入口。

### 1.2 电费比较 → 自然周期同期
- 电费 tile 徽标（原「较上窗口 Δ%」）改为：
  - 24h：今日 00:00–现在 vs 昨日 00:00–昨日同一时刻 →「较昨日同期」
  - 7d：本周一 00:00–现在 vs 上周一–上周同一时刻 →「较上周同期」
  - 30d：本月 1 日 00:00–现在 vs 上月 1 日–上月同一日同时刻 →「较上月同期」
- 当前/上一周期各自取窗口内真实采样点，累计下降（`deriveRange`，不插值、扣减规则沿用）；
- **两周期采样覆盖均 ≥35% 窗口才显示**（历史数据不足时不硬凑、不显示误导百分比）；徽标 `title` 写明统计时段；颜色沿用原有下降/上升样式。
- 取数：补拉更长窗口（7d→14d、30d→70d 隐藏 `PW_RANGE_MAP` 键），`ensureCompare` 按需异步补拉后刷新 tile；`fetchHist` 增加 in-flight 去重（force 也复用进行中请求），刷新/切档不重复请求同一窗口。

## 4. 副作用 / 已知限制（如实）

1. tile 主数值仍是「近 N 天窗口用电」；比较徽标百分比按自然周期同期计算（两者口径不同，UI 已用「较昨日/上周/上月同期」区分）。
2. 现网 `power_history` 历史深度约 6 天 → 「较上周同期」「较上月同期」暂不显示；数据积累到 14/70 天后自动出现（数据不足时按覆盖率规则隐藏，不硬凑）。
3. 仅网页端改动；小程序端未改（如需同口径需另改 mp 并随用户上传发布）。
4. 13/16 隐藏 24h 是楼栋级固定策略：即使网关提速（isSlowRoom 降级实时口径）也不重新显示 24h 档。
5. 程序化 `setRange("24h")` 仍可切到 24h（测试/深链），但用户界面无入口；不影响「隐藏趋势图」的交付口径。
