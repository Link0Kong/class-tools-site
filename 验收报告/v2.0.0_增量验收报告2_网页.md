**B. QA 独立行为断言（`qa_web[notice_slow_swipe]`，3 条 PASS）**
- 静态阈值：全局 `if(Math.abs(dx)<4)return;` + iframe 适配 `Math.abs(dx)<4&&Math.abs(dy)<4` + 横纵比 `1.2`（无 12px 死区）✅
- 通知 iframe 慢速横滑（合成 touch）：**首个生效位移 = 4px（≤6px）**；每次 handler 落 transform 与该次 dx **同步误差 0.0px（≤2px）**；40px 未达阈值回弹、不切工具 ✅
- 全局手势慢速：transform 与该次 dx 同步误差 0.0px；2px 死区内不跟手；锁定前纵向不劫持 ✅
- PEND 说明：headless 父页文档输入管道存在 ~16px slop（首个 touchmove 才派发给 JS），无法在父页文档直接测「首 4px」；以 **iframe 适配层实测首效 4px + 静态阈值 + v2_swipe_perf slow4px 指标** 三重覆盖（产品在真机上的慢速路径即适配层→父页引擎）。

## 4. 结论

- **微信内滑动第二批修复：PASS**
