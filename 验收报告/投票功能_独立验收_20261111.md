## 4. A. 云端黑盒（116 项，`vote_qa_cloud.py`）

分组：准备 2 · 鉴权/直连表 9 · 创建参数边界 26 · 结构与隐私 9 · 投票规则 18 · 可见性 9 · 实名 5 · 服务端截止 5 · 管理/权限/编辑 15 · 软删除 5 · 注入/类型对抗 7 · 响应 JSON 1 · 清理复查 5。

关键证据（摘要）：

- **鉴权**：无 token / 伪造 token / DB `expires_at` 已过期的 token → `{ok:false,"身份已失效…"}`；`X-Class-Token`（小程序头）与 `X-Device-Id`（网页头）等价可用。
- **直连表全拒**：`GET /polls`、`GET /poll_votes`、`POST /polls`、`POST /poll_votes` 均 401（`permission denied for table polls/poll_votes`，实测 `status=401`）。
- **创建边界**（逐项实测拒绝/接受）：标题 空白/81 拒绝、80 接受；说明 500 接受 / 501 拒绝；选项 1、21 拒绝、20 接受（含选项文字 80 字、选项说明 200 字成功；81 字、201 字、空白、非法 id、重复 id 拒绝）；图片 `https://` 拒绝、单张 150001 字符拒绝、12×139919 合计超 1.6MB 拒绝；`resultVisibility` 非法拒绝；`multi=true,maxChoices=1` 拒绝；`maxChoices=25 > 选项数` → 归一为 3；单选 `maxChoices=7` → 归一 1；deadline 过去/负数拒绝；p_id 非法/超长拒绝；`mode` 非法归一 `long`。
- **幂等**：同 `p_id` 重复发起返回同一投票、**不覆盖原内容**、列表仅 1 条。
- **一人一票 / 改票**：单选 1 票成功；同 sid 改票 upsert（total 仍 1、counts 替换）；`allowChange=false` 二次提交 → `已投过票，不可改票` 且记录保持首次选择；他人投票 total 累加。
- **上限/合法性**：单选提交 2 项 → `只能选 1 项`；多选 3 项（max 2）→ `最多选 2 项`；重复 → `重复的选项`；空/不存在/非字符串 → `选项不合法`。
- **匿名/实名**：匿名 `voters` 恒为 `[]`；实名 `voters` 返回 `name/choices`、**不含 sid**；测试身份实名投票人姓名 = `测试账号`（服务端按 `private.class_ids` 写入）。
- **三种可见性**：`afterVote` 未投隐藏（`counts={}`）投票后可见；`always` 0 票即见、未投第三方也见；`afterClose` 投后仍隐藏、`my_choices` 仍回显、提前结束后可见、列表与详情一致。
- **服务端时间**：SQL 把 `deadline` 改为过去（模拟 DB 时间到达）→ 提交被拒 `投票已结束`、详情 `closed=true` 且 `status` 仍 `open`（到期不写库）；列表 `closed` 与 DB 一致。
- **管理**：非发起人 close/extend/delete 全部 `无权管理该投票`；发起人 close → `closed=true,closed_at>0`；extend 过去 → `截止时间需晚于当前时间`，extend 未来 → 重开可投；`edit` 仅 0 票可用（标题/选项/规则/截止全部更新），有票 → `已有投票，不能修改内容`，缺参 → `参数不完整`；未知动作 → `不支持的操作`。
- **软删**：`{ok:true,deleted:true}` → 详情 `投票不存在`、列表不返回、不可投票、再管理返回不存在。
- **注入/类型对抗**：标题/选项含 `'; drop table public.polls;--`、`<script>` 原样存储且无报错，随后列表仍正常（表未被破坏）；`p_id` 注入串被正则拒；`p_options` 非数组、`p_choices` 非数组 → 中文 reason 拒绝；`p_id=null` → `投票不存在`（无 500）。
- **响应 JSON/隐私**：97 个 `poll_*` 原始响应全部为 JSON 对象；扫描 34 份响应原文：**无 `"sid"` 字段、无 `owner_sid`、无任何测试身份/合成 sid 数字**。

清理证据：`delete from public.poll_votes/polls where id in (…)` 后逐 id 复查均不可查、列表无残留；5 个 token 删除后 QA token 立即失效；最终 `poll_list` 返回 `polls_total=0`。
