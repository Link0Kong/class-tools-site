# 投票「可见人范围」增量 · 交付说明（2026-11-11 18:08）

> 用户需求：「投票功能新增可见人范围选项」。本文件 = 实现者（Lead）交付说明；独立验收见同目录 `投票功能_可见范围_独立验收_20261111.md`（QA 出具）。

## 1. 需求确认与口径（已向用户确认）

| 项 | 结论 |
|---|---|
| 范围选项 | **全班（默认）/ 班委 / 团员 / 指定成员**（指定成员从班级名单多选，内部用**座号**存储，不存/不显示学号） |
| 范围外权限 | **列表完全看不到**（不暴露存在性）；详情/投票接口返回「投票不存在」；不能投票、看不到结果 |
| 发起人 | 始终可见、可管理、**可投票**（即使不在「指定成员」名单里） |
| 管理员 | 始终可见、可管理；**不在范围内时不能投票**（返回 reason「不在可见范围内」） |
| 判定口径 | 班委 = `private.class_ids.role` 非空或 `badge` 含「班委」；团员 = `private.class_league` 名单；指定成员 = 座号命中；全部服务端判定 |
| 编辑 | 仅「尚无任何票」时可修改可见范围；已有票后只能结束/延长/删除 |

## 2. 实现

### 2.1 云端（迁移已应用，幂等）

- 文件：`deploy/cloudbase/2026-11-11_polls_audience.sql`（基础迁移 `2026-11-11_polls.sql` 不变）。
- `public.polls` 新增：`audience text NOT NULL DEFAULT 'all'`（CHECK：all/committee/league/custom）、`audience_seats jsonb NOT NULL DEFAULT '[]'`（座号数组，去重升序，排除 is_test）。
- 新增内部函数：`poll_audience_visible()`（范围判定）、`poll_norm_audience()`（归一/校验）。
- 签名变更：`poll_create` 新增 `p_audience text DEFAULT 'all'`、`p_audience_seats jsonb DEFAULT NULL`；`poll_manage` 新增同两参数（NULL=不修改，旧版页面兼容）。
- `poll_list`/`poll_detail`/`poll_submit` 增加服务端可见性过滤；`poll_detail.poll.audience_seats` 仅 `can_manage` 返回；任何 RPC 响应都不返回学号。
- 语义细节见契约 `web/vote/CONTRACT.md` §1.6/§2。

### 2.2 网页（`tools/index.html`，APP_VER 仍 2.0.0，纯增量）

- 发起/编辑弹层新增「可见范围」4 段（`#voteAudience`）；选「指定成员」显示 `#voteAudBox`：

  未选成员时客户端 toast「请选择可见成员」拦截。
- 提交/编辑 payload 增加 `p_audience` / `p_audience_seats`（custom 为升序座号数组，其它为空数组）。
- 列表卡片/详情弹层增加范围标签：「班委可见 / 团员可见 / 指定 N 人」（全班不显示）；编辑按服务端返回回填。
- 原有投票功能（限时/长时、选项/配图、规则、结果可见性、管理）不受影响。

## 5. 已知限制 / 取舍（如实）

1. 范围外**完全不可见**（含存在性），`poll_detail`/`poll_submit` 统一返回「投票不存在」；
2. 管理员始终可见/可管理，但不在范围内不能投票（避免管理员越权投票）；
3. 指定成员只保存/回填**座号**（不存学号、RPC 不返回学号）；名单变更（转班/新增）需重新编辑；
4. 编辑可见范围仅限「尚无任何票」；已有票后不可修改；
5. 旧数据无 `audience` 字段时按「全班」处理、不显示范围标签；旧版缓存页面创建投票为全班、编辑不改变原范围；
6. 小程序端需用户上传发布后在真机生效（版本仍 2.0.0）。
