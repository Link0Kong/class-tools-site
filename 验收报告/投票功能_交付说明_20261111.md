# 投票功能 · 交付说明（2026-11-11）

> 用户需求：「新增投票功能，该功能需同时可用于临时的限时投票和可设立截止日期的长时投票，投票选项和投票标题需可高度自定义化」。
> 本文件 = 实现者（Lead）交付说明；独立验收见同目录 `投票功能_独立验收_20261111.md`。

## 1. 需求复述与已确认取舍

| 需求 | 落地 |
|---|---|
| 可同时用于「临时限时投票」 | 发起时可选手动限时快捷：**5 / 10 / 30 分钟、1 / 2 小时**（截止 = 创建时刻 + N 分钟，服务端按 `clock_timestamp()` 判定） |
| 可设立截止日期的长时投票 | 发起时可选「指定截止」：`datetime-local` 选日期+时间（跨天/跨周均可）；也可选「不限时」 |
| 投票选项高度自定义 | **2–20 个选项**，每项：文字（1–80 字）+ 补充说明（≤200 字）+ 可选配图（客户端压缩成长边 ≤640 的 JPEG data URL，单张 ≤150000 字符、合计 ≤1.6MB）；支持上移/下移/增删；可配**单选/多选 + 最多可选几项** |
| 投票标题高度自定义 | 标题 1–80 字 + 说明 ≤500 字（多行），规则另选：匿名/实名、是否允许改票、结果可见时机（始终 / 投票后 / 截止后） |
| 谁可发起 / 管理 | 全班成员都可发起；发起人与管理员可编辑（仅当尚无票）、提前结束、延长/重开、删除（软删） |
| 一人一票 | 服务端 `poll_votes UNIQUE(poll_id, sid)` 去重；匿名投票不返回投票人（服务端仍按 sid 去重） |

已与用户确认的范围：**本轮做网页 + 小程序源码**（安卓后续）；**完整版自定义规则**；**全班成员可发起**。

## 5. 已知限制 / 取舍（如实）

1. 投票页**不提供图片导出**（避免投票人姓名/学号进入导出物）；
2. 选项配图以 data URL 存 `polls.options`，单投票总配图 ≤1.6MB（大图会压缩，极端复杂图可能提示换一张）；
3. 匿名投票只是**不对外返回投票人**（服务端仍按 sid 去重/防重复，数据库管理员可查原始行）；
4. 投票数据是云端共享表，**不进** `userdata` v6（无新同步 section）；
5. 编辑仅限「尚无任何票」；已有票后只能提前结束/延长/删除；
6. 投票人姓名来自班级名单（`private.class_ids`），非班级身份不可见班级数据；合成 QA 会话的姓名可为空（仅测试用）；
7. 小程序端图表/交互为 WXSS 风格复刻，未做真机自动化（需用户上传发布后真机验收）。
