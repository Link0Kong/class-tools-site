# PPT 演示 · 使用说明（班级工具站 2026-11-09）

> 一句话：**上传 .ppt/.pptx → 家里电脑自动转换 → 任何设备（老教室电脑 / 手机 / 平板）流畅播放，嵌入视频也能播。**

## 一、三端入口

| 端 | 位置 |
|---|---|
| 网页 `tool.furina.fun` | 身份通过后，顶部工具栏或「全部」页里的「**演示**」卡片（可拖进首页快捷，最多 4 个） |
| 微信小程序 | 底部「工具」→ 全部工具 →「**演示**」 |
| 安卓 App | 「全部工具」→「**演示**」 |

## 二、怎么用（3 步）

1. **上传**：点右上角「上传 PPT」→ 选 `.ppt` / `.pptx` 文件（≤ 60MB，建议含大视频的 PPT 先压一下）→
   可改标题 → 开始上传。小程序要从**微信聊天记录**选文件（先把 PPT 发到任意微信聊天里）。
2. **等转换**：上传完成自动进入排队；家里电脑（转换机）开机并登录后自动转换。
   - 状态：`排队转换` → `转换中 61%` → 可直接播放；
   - 转换机没开时显示「转换机离线 · 排队中」，开机后自动继续，**不用重新上传**；
   - 参考速度：普通 16 页约 10 秒；页数多 / 含大视频会更久，最长约 15 分钟兜底。
3. **播放**：点卡片进入全屏。
   - 下一页 / 下一个动画：**点屏幕右 2/3**、`→`、`Space`、`PageDown`、手机右滑；
   - 上一页 / 上一个动画：**点屏幕左 1/3**、`←`、`PageUp`、手机左滑；
   - 控制条 3 秒自动隐藏，动一下鼠标/触摸即出现：上一页、页码、下一页、缩略图、备注、黑屏、全屏、下载原件、退出；
   - 缩略图可跳任意页；`B` 一键黑屏（任意键恢复）；`N` / `S` 打开备注；`Esc` 退出（有进度会先确认）；
   - **视频**：该页视频位置会出现 ▶ 圆形按钮，**点一下才播放**（不会自动播）；播完或点 × 回到本页。
4. **班级共享**：任何班级成员上传后，全班三端都能看到；只有本人（或管理员）能删除。

## 三、效果说明（如实）

- 所有页面内容**完整显示**：文字、图片、表格、图表、嵌入视频都在。
- 为了保证「任何设备都不卡」，播放用的是**转换后的分步图片 + 抽出的视频**，不是实时跑 PowerPoint：
  - 同一段文字里**逐字/逐条出现**的动画会合并成整段出现；
  - 强调动画、运动路径只保留该步的**最终画面**；
  - 自动连播的动画（不点鼠标自己动的）合并为当页最终画面。
- 指向**外部文件**（不是嵌入到 PPT 里）的视频无法带出，会自动跳过（原画面仍在）。
- 教室电脑只需要浏览器，**不需要装 PowerPoint**；每页图片仅约 20–40KB，老电脑也秒开。
- 转换机 = 家里这台装了 Microsoft PowerPoint 的 Windows 电脑；它必须开机并登录（计划任务每分钟自动检查）。
  关机期间上传的会排队，开机后自动转换。

## 四、微信小程序发布前必须做（需要你操作）

1. 打开 **微信公众平台 → 开发管理 → 开发设置 → 服务器域名**：
   - 把 `https://tool-furina-fun.oss-cn-hongkong.aliyuncs.com` 加入 **request 合法域名**；
   - 同时加入 **downloadFile 合法域名**（图片/视频资源用）。
2. 用**真机正式版**打开小程序验证三项：列表封面能显示、播放器图片能加载、含视频 PPT 的视频能播放。
   - 图片全白 → 检查域名白名单 / 小程序是否保留 `<image webp="{{true}}">`；
   - 视频不能播 → 检查 downloadFile 域名；若 OSS 开了防盗链，需放行**空 Referer** 与 `servicewechat.com`。
3. 微信开发者工具「上传」→ 公众平台提交审核 → 发布（版本号仍 2.0.0）。
4. 香港 OSS 默认域名能否通过微信校验**未查证**；若被拒，需要给 OSS 绑已备案的自定义域名（改动只在转换机常量 + 微信后台域名，代码不用动）。

## 五、安卓

安装 `班级工具站_PPT演示_安卓.apk`（版本 3.3.0）→ 与网页同账号（首次进入输学号+姓名）→ 全部工具 → 演示。

## 六、给技术侧（维护）

- 契约（唯一真源）：`web/ppt/CONTRACT.md`；设计参考：`web/ppt/DESIGN.md`；转换机运维：`web/ppt/README.md`。
- 转换机计划任务：`PptConvertAgent`（每分钟检查一次；Interactive only，需桌面会话）。
  - 查看：`schtasks /Query /TN PptConvertAgent /V /FO LIST`
  - 暂停：`schtasks /Change /TN PptConvertAgent /DISABLE`；恢复：`/ENABLE`
  - 日志：`web/ppt/logs/agent-YYYYMMDD.log`；手动转一轮：`python web/ppt/agent.py --once`
- 网页回滚：重传 `web/tools/_backup/index_online_20261109-2220_prePPT.html`。
