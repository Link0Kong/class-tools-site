# PPT 演示 · 交付说明（2026-11-09，三端同步）

> 需求（用户 2026-11-09）：教室电脑老旧 → PPT 动画多时卡死/无响应；别人电脑能播的嵌入视频换到班级电脑显示「媒体不可用」。
> 目标：**可在任意设备上完整流畅播放 PPT、任何人可上传**，三端同步上线。
>
> 做法：上传端只传源文件 → 家里电脑「转换机」（Windows + PowerPoint COM）一次性渲染**分步图片**（每页 + 每个点击动画步）
> 并抽取**嵌入视频/音频转 H.264/AAC** → 三端只加载图片/MP4（老电脑也秒开，视频不再依赖 PowerPoint 解码器）。
>
> 唯一契约：`web/ppt/CONTRACT.md`｜设计：`web/ppt/DESIGN.md`｜转换机运维：`web/ppt/README.md`｜
> 开发记录：`web/HANDOFF.md` 末节「增量 28」｜架构说明：`web/AGENTS.md` §4b-20、`web/CLOUDBASE.md`。

## 三、已知限制（设计取舍，均已写入契约/README）

1. 分步图取「每步最终视觉态」：同段逐字出现合并、强调/运动路径取快照、自动动画合并为当页最终态（**内容不丢**）；
2. 外链媒体（非嵌入）跳过；隐藏页仍转换；
3. 转换机需开机 + 登录（离线只排队）；PowerPoint 正被用户编辑时本轮跳过；
4. 单 deck ≤ 64MiB / ≤ 300 页 / 图 ≤ 260 张 / 每页 step ≤ 12 / 媒体总时长 ≤ 30min（超出降级或跳过，不丢内容）；
5. 重转换时旧 buildId 资产不自动删除（占用很小）；
6. 媒体资产在 OSS 公共读（URL 含 128bit 随机 deckId，不可枚举）——班级 PPT 视为班内公开材料；
7. CloudBase 环境 2026-12-10 到期，需续费/迁移。
