## 3. 滑动手感指标（`v2_swipe_perf.py` 三档独立复跑）

三档：`baseline` = v2 前冻结版（同步直写）；`prefix` = v2 卡顿版（rAF 合并，用户反馈版本）；`fixed` = 当前线上。

| 指标 | baseline | prefix（问题版） | fixed（当前线上） | 判定 |
|---|---|---|---|---|
| reactionRate（跟手反应率） | 1 | **0** | **1** | 恢复 baseline 手感 ✅ |
| syncErrP50 / P95（px） | 0 / 0 | 20 / 20 | **0 / 0** | 不再滞后 20px ✅ |
| applyLatencyP50（ms） | 0 | 0.10 | 0 | 同步直写 ✅ |
| frameP95（ms） | 28.10 | 28.60 | **28.30** | 与 baseline 持平（±0.3ms）✅ |
| longFrames（>32ms） | 1 | 1 | **1** | 与 baseline 相同 ✅ |
| posWritesDuringScroll | 0 | **10** | **0** | 滚动期间不再写 sessionStorage（不抽动）✅ |
| posWritesAfterSettle | 0（baseline 无 POS） | 10 | **1** | 停止后落盘 1 次（需求 2 保位不受影响）✅ |

逐场景（toolbar 切工具 / notice 通知页）均 reaction=1、syncErrP50=0、P95=28.3ms、long=1、boot=True、errs=[]。

**结论：修复版与 v2 前 baseline 手感逐项对齐，同时保留 v2 的「刷新保位」落盘行为（滚动期间 0 写、停止后 1 写）。**
