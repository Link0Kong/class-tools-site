## 一、变更摘要

### 1. 云同步显性化 + 加固（web）

| # | 改动 | 验收点 |
|---|---|---|
| 1 | `#wtSync` 同步状态（hero 底部，复用 `.pw-sync`） | 未选宿舍隐藏；同步完成 `data-sync=1`+「已同步」；本机有脏数据 `data-sync=0`+「未同步 · 点重试」 |
| 2 | `WATER.requestSync()`（点重试） | 有基线立即 `UD.push(true,["water"])`；无基线 `UD.pull(true)` 建基线后补推 |
| 3 | `WATER.normWater()`（新增）+ `applyRemote`/`UD.sections` 接入 | 远端 `p=9→4`、130 条→120（2010-11 起）、非法月份/负读数/坏房间丢弃；回云 POST 也是归一值 |
| 4 | `WATER.enter()` 补拉 | 本机缓存无 water（旧缓存/首装）时强制 `UD.pull(true)`，其余 60s TTL |
| 5 | `save/del/setPersons` → `UD.pendWrite(["water"])` | 无基线/推送失败时下次 pull 保本机赢 |
| 6 | `syncState` pending 判据修正（去 `_push`） | 推送完成不再闪回「未同步」 |
| 7 | 使用说明同步清单 + 水量段说明 | 「按账号同步」含关注宿舍、水量抄表记录；平台内可自查 |

`at.water` LWW；water 值内不镜像 at；旧数据默认 `{rooms:{}}`；未拥有端原样保留。
