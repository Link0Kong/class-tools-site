## 7. P2 / 已知限制（如实）

1. **【P2·验收夹具】** 首轮 `run_v4_final4` 的 A50/A51/A52 三项失败为**夹具观测方式问题**（toast 1.9s 自动消失 + 轮询 2s 时序；Esc 派发目标/重开时序），非产品缺陷：Lead 用独立 CDP harness 复核三项 PASS；本报告最终轮已改为 MutationObserver 捕获 toast、放宽状态等待、Esc 前显式确保大屏重开，**91/91 全 PASS**。
2. **【P2·UI 细节】** 投票「指定成员」勾选后 `#o2sCrtMemSum` 的「已选 N 人」文案只在表单重渲染时刷新（点座号即时不更新）；提交 payload 正确（2 座），不影响功能。
3. **【P2·视觉细节】** 灵动岛展开时 `#o2sIsland` 的 `.open` class 运行时未被添加（`stgRenderIsland` 只渲染下拉、`stgIslandClose` 才 remove），胶囊展开的圆角/内边距样式不生效；下拉功能正常。
4. **【设计已知限制】** 浏览器不能强制 PowerPoint 全屏（需按 F5）；WPS 无远程打开协议→需下载后打开；已下载标记/布局均为**本机偏好**（不跨端同步）。
5. **【服务已知限制】** 互联会话 TTL 2h / 关闭即删；签名下载 URL 30 分钟过期（旧链接需重传）；同 sid 才能互见（同账号多设备）；ECS 单实例（单文件 2GiB/会话 8GiB）。本报告未对 2GiB 上限做压测。
6. **【未验证/未覆盖】** 未在真机移动浏览器验证（430 为 headless 触摸模拟）；控制器侧使用本地 mock `/drop`（真实 ECS 已由黑盒 25/25 覆盖，但未做「真实服务 + 页面前端」联调——需真实班级 token 注入页面，按纪律不用真实 token）；PPT 打开未真的触发 `ms-powerpoint` 外协议（按要求只验证按钮/`hrefOf`/提示）；`optim_v2_check` 等回归在**工作区 834d39cc** 上跑（与线上对象同 sha）。
7. **【既有夹具】** `overflow_check.py 430` 的 headless 实际 `innerWidth=492`（脚本窗口尺寸换算现象，非本轮引入）；真实 430×900 无溢出已用 CDP 复核。
