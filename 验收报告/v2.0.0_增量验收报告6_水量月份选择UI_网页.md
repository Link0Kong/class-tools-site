## 一、问题与方案

**问题**：水量页「月份」原为原生 `<input type="month">`，全局输入框样式未覆盖该类型（只覆盖了
text/password/date/time/number），桌面显示浏览器默认月历控件，边框/圆角/字号/配色与旁边「读数」输入框和整站暖白卡片不一致，也不美观。

**方案**：保留 `#wtMonth`（type=month）作为**隐藏真实值**（保存/预览/自动对比/测试契约不变），
外加站内自绘月份选择器：三段式「‹ 上一个月 ｜ YYYY 年 MM 月 ｜ 下一个月 ›」+ 点开 12 个月网格弹层。
零依赖、原生 JS、无构建链、无外部资源。

| 组件 | 设计 |
|---|---|
| 触发控件 | 42px 高、暖白底/暖沙细边/圆角 10（与站内输入框同族）；左侧日历图标、「2026 **年** **11** 月」（年小月大层级）、右侧展开箭头（展开时旋转）；聚焦时青边+3px 光晕 |
| 月步进 | 两侧 ‹ › 直接 ±1 月（跨年自动进位/借位，2000–2100 钳制），不必开弹层 |
| 弹层 | fixed 锚定控件下方（空间不足自动向上、左右自动收边），296px 宽；头部「‹ 年份 › + 本月 + ×」；12 个月 4×3 网格 42px |
| 状态表达 | 选中月=浅青底+青边+深青字；当前月=暖沙描边；**已有抄表记录的月份下方 4px 小圆点**（一眼看出哪月已抄） |
| 关闭 | 选月/点空白/Esc 关闭（Esc 回焦触发按钮）；切页、窗口缩放、页面滚动自动收起（fixed 防错位） |
| 无障碍 | `aria-haspopup=dialog`、`aria-expanded`、`aria-labelledby`、`aria-current`、方向键在月份间移动焦点、Enter/Space 选择 |
| 禁用 | 未选关注宿舍：触发/‹/› 与隐藏 input 均 disabled，弹层不可打开 |

## 二、契约兼容（关键）

- 真实值仍是 `#wtMonth`（`type=month`，1px / opacity 0 / tabindex=-1）：`WATER.save()` 读值、`renderPreview()` 读值、
  `water_check` 的 `set_input("#wtMonth", ...)` / `jval` / `jdisabled` 全部不变。
- 隐藏 input 的 `input/change` 事件 → `WATER.onMonthInput()` 反向同步标签与预览（程序化改值也生效）。
- 数据/同步零变更：仍写 `water.rooms[rv].recs`（月升序/≤120 条），`D.save()`/UD v6 water section/LWW 合并均未动。
