## 0. 结论先行

1. **团日现场缺的不是「更多卡片」，而是主持人不出错**：一屏只推进一个阶段、所有读数用大数字、所有操作有键盘等价物、断网也能用、误触能回退。现有 4 卡里只有「计时」「抽签」属于团日，「下一节」「作业」应移除（与用户判断一致）。
2. **与 PPT 联动的最小闭环**：大屏 → 共享演示库 → 全屏播放 → **退出后回到大屏原环节**（而不是弹回工具页/上一个 tab）。播放器已有备注、缩略图、黑屏、键盘、左右滑，不需要重写播放器。
3. 最值得抄的三类案例：**议程/时间线视角**（微媒，把"rundown 表"搬上大屏）、**计时器全屏规格**（hi8，3 秒淡出控件 + 超时正计时 + 绝对时刻计时）、**抽签大屏清单**（968T，不重复/连抽/全屏/历史）。
4. 最需要避开：扫码签到、弹幕上墙、实时投票抢答（都要外部服务或长连接服务）、抽奖「黑幕/权重」（不诚信）、大屏暴露学号/手机号/宿舍号（红线）。
5. **推荐第一批只做 F1 外壳 + F4 计时器**（约半天到一天、不碰契约、回归面最小），第二批 F2 议程 + F5 抽签，第三批 F3 PPT 联动；P1 的知识竞答/宣誓页/出勤板视时间追加。

### 2.5 案例小结（跨案例共性）

- **所有「大屏」产品都在做同一件事：把主持人的脑内流程外化成屏幕状态。** 微媒叫「时间视角」、PowerPoint 叫「演示者视图」、hi8 叫「大屏标题 + 超时 +」，本质都是让台上那个人不用记流程、不用看手表。
- **越像「现场活动」的产品，越依赖外部服务**（扫码、实时投票、弹幕、抽奖云端同步）；越像「单人主持工具」的产品（hi8、968T）越纯前端。本站的架构天然适合后者——这也是必须放弃扫码/弹幕/实时投票的根本原因，不是不想做。
- **团日典型环节与画面形态的对应关系**（据 A1/A2 + 各地团日报道归纳）：签到→出勤数字；开场→主题大字/欢迎页；团课→PPT 播放；视频→播放器；竞答→题干+倒计时+计分板；宣誓→誓词大字页；合唱→歌词页；合影→倒计时；结束→总结/合影。**8 个环节里有 5 个是「一页大字/一屏信息」，这正是单文件站点最容易做好的部分。**
- **主持人真正会用的按键不超过 8 个**：空格、←→、F、Esc、B、R、P，加一个「抽」。案例里没有任何一个产品要求主持人在现场用鼠标点小按钮。

### 3.1 三条落地原则（从案例共性里抽出来的）

1. **一屏只能有一个「当前阶段」**：其余信息降到标签级（微媒时间视角、hi8 全屏、PowerPoint 演示者视图都如此）。现有 4 卡平铺等于「没有主次」，这是要改的根本原因。
2. **所有操作必须有键盘等价物**：主持人站在台前、手可能拿着稿子，鼠标是最差输入设备；案例里空格几乎一律是「开始/停止」。
3. **声音必须 WebAudio 合成**：hi8 用外链音频，本站红线不允许；且浏览器要求先有用户交互才能出声（hi8 文档也写明），所以第一声提示靠点击「开始」那一下解锁音频上下文，属于可接受行为。

### 3.2 明确「不抄」的 5 个做法

| 做法 | 出处 | 为什么不抄 |
|---|---|---|
| 后台默认密码 / 隐藏入口 | appinn 抽奖系统（默认密码 appinn） | 安全后门；本站已有学号+姓名换 token 的登录，不需要第二套口令。 |
| 抽奖权重 / 必中 / 禁中 | appinn、部分年会抽奖系统 | 违背公平，团日场景会引发同学矛盾。 |
| 头像墙 / 3D 签到墙 | Hi现场、微现场 | 需上传头像与外部服务；隐私与性能双风险。 |
| WebSocket 毫秒级多屏同步 | lucky-draw | 需要常驻服务进程，破坏「双击 HTML 即用」的交付形态。 |
| 二维码配对手机遥控 | WPS、Keynote、uClass | 需要服务端发现/中继；本站只能做站内 URL + 数字码 + 云端轮询（P2，且需先批准新表）。 |

### 6.4 现场风险与兜底（团日当天的「万一」）

| 风险 | 现场表现 | 兜底做法 |
|---|---|---|
| 投影分辨率/比例不对 | 大字被裁切、进度条超屏 | 全部尺寸用 `vmin`/`clamp()`；提供「字号 -/+」两档（抄 hi8）；活动前 10 分钟试投一次。 |
| 教室电脑太老 | 动画掉帧、切阶段白屏 | 抽签滚动用 transform 不触发重排；阶段切换只换文本与 CSS class；低端机降级为无动画（可复用 PPT 块的 `LOWEND` 判定思路）。 |
| 浏览器全屏失败（微信内置/权限） | 顶部露出地址栏 | 提供「伪全屏」：固定定位 + 隐藏滚动；同时提示按 F11。 |
| 投影/电脑声音被静音 | 到点没声音 | 到点必须有视觉提示（变色 + 闪烁），声音只是辅助；不要依赖声音判断结束。 |
| 断网/WiFi 挂了 | 演示库列表拉不到 | 主持台纯本机功能全部可用；PPT 播放走已加载的 OSS 图片/视频（若未加载则提示「需要网络」）；活动前把要用的 deck 打开一次预热。 |
| 误触空格把阶段推进过头 | 议题跑偏 | 「下一环节」可撤销（Alt+← 或 Z）；议程页可点击任意环节跳转。 |
| 主持人手抖/紧张 | 不知道该按什么 | 控制条上每个按钮带中文短标签 + 快捷键提示；欢迎页放一张「操作说明」小卡（按 ? 显示，默认隐藏）。 |
| 手机热点给演示库用 | 上传/转换不受影响（转换在本机） | 不需要现场上传；活动前把 PPT 上传并等转换完成即可。 |
