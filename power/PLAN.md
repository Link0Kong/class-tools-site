> 状态：**班级工具站「宿舍电费」v5 已上线；小程序端已同步（代码/测试完成，待上传发布）**

## 结论

本校电费走 **完美校园「缴费 → 用电支出（预付费）」**，背后是**新开普云支付网关**。
**查询剩余电量不需要登录**（学校码 + 缴费项目 ID + 房间 ID 即可）；只有充值需要账号与支付密码。
老引擎「智能水电」对本校不可用（schoolcode=769 返回 8099 body格式错误）。

## 已上线：班级工具站「宿舍电费」v5

入口：https://tool.furina.fun/ → 学号+姓名登录 →「全部」→「**宿舍电费**」卡片。

- **统一命名**：13号楼324 / 16号楼305 / 23号楼A座321 / 23号楼B座422（DB 主键 = roomverify）。
- **单选关注**：下拉框选择宿舍；选择进 userdata v6 `power` section，换设备/浏览器可恢复。
- **v5 数据仪表盘**：
  - 电量环（刻度 = 估算可用天数 / 30 天）+ 大字电量 + 状态
  - **估算可用（v5 算法）**：24h + 7 天双窗口分段统计（充值跳变整段跳过），0.65:0.35 混合，速率下限 0.05 度/天；≥30 天显示「≥30 天」并满环；tile 副标「≈X 度/天」
  - **低电阈值可调**：点 tile 弹 8 档（10–100 度）；默认 30；`q<low` 低电、`low≤q<low×2` 偏低；随账号同步（`power={sel,at,low}`）
  - 趋势 24h/7天/30天，右侧固定竖坐标轴 + 横向滑动（不触发站点横滑切工具）
  - 上次充值（历史跳变检测：时间 + 重置度数）、区间用电、低电提醒条
- **空间**：桌面两栏撑满视口；平板横排；手机纵向三段；空态/加载/错误态高度稳定。
- **数据**：`public.power`（当前值）+ `public.power_history`（每小时采样，保留 30 天）；本机计划任务 `ClassPowerSync`。
- **线上版本**：**532,533 B · sha256 `e38bddcf…f09a`**（本地=线上；真实登录冒烟 22/22）。
