# 班级工具站 · 完美校园电费（研究 + 工具包）

班级工具站「宿舍电费」功能的研究资料与本机工具包归档。

- `PLAN.md`：方案摘要、已上线能力、数据契约与风险。
- `research/`：接口协议、GitHub 侦察、UI 评审。
- `src/`：完美校园免登录查询工具（MIT，vendor 自 `jialiangh/campus-electricity-monitor`，见 `src/NOTICE`/`LICENSE`）；本机配置与电量快照不入库。
- `deliver/`：方案报告与离线看板。
- `tests/`：自检与冒烟。

> 站点侧电费实现（网页 / 小程序 / 安卓 / 鸿蒙）在各自主仓库；本仓库只保存研究与本机采集工具包。

主站仓库：GitHub `Link0Kong/class-tools-site` / Gitee `ko_Link/class-tools-site`。
