# 班级工具站 · 备案内容自查（2026-11-06）

> 对象：`https://tool.furina.fun`（H5，单文件）｜备案：阿里云 ICP 备案（审核中）
> 结论：**功能层面没有备案禁区，首次备案阶段网站关闭、管局按申报信息审核，功能不会直接导致被拒；真正的风险在「备案通过后内容核查」与「网站名称/备注的定性」。** 以下按功能逐项过一遍，列出需要在上线前处理的点。
> 注：本表为风险自查，不是管局结论；管局有裁量权。

## 二、三个真正要处理的点

1. **教育类定性信号**：站点文案里有「学校 / 校园 / 课程 / 作业 / 课表 / 体测 / 成绩 / 学生 / 教师 / 专业名」等（全文检索：课程 20、作业 20、成绩 13、课表 41、体测 22；另有「福建中医药大学」「国家学生体质健康标准」）。
   - 好消息：教育网站审批已于 2016 年取消（国发〔2016〕9 号），且本站**没有**培训、课程销售、视频教学、学科内容——不是「教育培训」。
   - 要做：网站名称/备案备注保持中性；公开页加「个人开发 · 非学校官方 · 仅本班同学使用」；上线后内容与申报一致；被问时按话术说明「班级事务辅助工具，非教育服务」。
2. **用户发布属性**：当前任何登录成员都能发布作业/通知 → 容易被看作「信息发布/交互服务」。
   - 建议：发布权限收口到管理员/班委（产品上一行权限判断即可），普通成员只读 + 标记完成/已处理；反馈保留（单向、非公开）。
3. **支付/导流字样**：「充值」8 处、「去完美校园充值」1 处。
   - 本站**没有任何支付代码**，但字样容易被审核员误判为支付/充值服务；改成「购电 / 余额提醒 / 学校官方渠道」，删第三方品牌名。

## 三、备案阶段和上线后分别看什么

- **首次备案审核期（现在）**：网站关闭待审。管局看主体/域名/接入/网站名称/服务内容/备注，**不依赖访问网站**，所以当前功能不会导致被拒。
- **备案通过后 30 天内**：网站上线，接入商/管局可能抽查实际内容，要求与备案一致：个人非经营性、无前置审批行业、底部挂备案号。这时上面三个点才会被看见。
- **上线后长期**：内容变了要变更备案；不能出现经营性内容、不能冒用学校名义。

## 四、电话/问询应答卡（照着说）

- 问：网站是做什么的？
  答：个人开发的班级事务小工具，本班同学凭学号姓名进入，用于抽签分组、课表查看、作业/通知清单、体测计算、宿舍水电查询；不是学校官方平台，不提供教育培训、课程、新闻或社区服务。
- 问：为什么必须登录？
  答：只服务本班 70 名同学，用班级名单校验身份，防止非本班人员查看班级数据；没有公开注册。
- 问：有没有收费、广告、支付？
  答：没有。水电页面只展示学校公布的标准和本人宿舍读数，不提供任何支付/充值功能。
- 问：内容从哪里来？
  答：班级公开通知和教务课表整理，仅本班可见。
- 问：网站名称？
  答：（与备案填写一致）页面标题「班级工具 · tool.furina.fun」对应。

## 六、决定结论的最大变量（待你确认）

1. 你备案填的**网站名称**是什么？
2. **服务内容**是否选的「其他」（个人网站应选其他）？
3. **备注**原文写了什么（有没有出现教育/学习/校园/学校/作业/课表等词）？

> 如果名称/备注中性（如「班级工具」「个人班级事务工具，非公开非经营性」），以当前功能通过首次备案的概率较高；如果备注里写了「作业/课表/教育/学校」等，人工核验时更可能被要求补说明——可在提交管局前撤回修改（若还来得及）。
