## 1. 研究口径与边界

1. **官方优先**：备案流程/费用以腾讯云备案文档、CloudBase 文档、阿里云 ICP 备案帮助中心、工信部文件为准；上架要求以华为/小米/OPPO/Apple 官方文档为准。

3. **区分硬性/经验**：每个关键结论后标 **【硬】** 或 **【经验】**，并在 §12 给出完整来源与查阅日期。
4. **价格口径**：只用「元/年」等可核对的数，逐项标【硬】/【经验】；不写「大概几十块」这类无法执行的表述。

## 3. 关键规则速查（决定路线可行性）

### 3.1 网站 ICP 备案（域名层）

| 项 | 规定 | 性质 |
|---|---|---|
| 谁要办 | 在**境内**从事非经营性互联网信息服务的网站主办者 | 【硬】《互联网信息服务管理办法》 |
| 前置条件 | ① 有**支持备案的境内云资源**（腾讯云：云服务器/轻量/云开发环境等）；② 域名注册商已获批复；③ 域名实名信息与主办者一致；④ 域名有效期剩余 > 45 天【阿里云口径】 | 【硬】 |
| 费用 | **腾讯云 ICP 备案免费**；备案「加急费」不存在官方通道 | 【硬】腾讯云文档 / 【经验】阿里云同样免费 |
| 周期 | 腾讯云初审（1–2 个工作日）+ 短信核验（部分省份）+ **管局 1–20 个工作日** | 【硬】时限 / 【经验】初审时长 |
| 个人限制 | 一次最多备案 **1 个网站 + 1 个 APP**；个人只能做个人博客、空间类、个人性质的网站，**不允许个人开办论坛**；网站名称需 ≥3 个汉字、禁用「博客/论坛/在线/社区/分享/平台/资讯/网站/网址」等词【阿里云经验文章口径】 | 【硬】腾讯云 FAQ / 【经验】命名细则 |
| 备案号悬挂 | 开通时须在**主页底部中央位置**标明备案编号，并链接工信部备案系统 | 【硬】《非经营性互联网信息服务备案管理办法》第十三条（微信备案指引原文引用） |
| 公安联网备案 | 网站上线后 **30 日内**到「全国互联网安全管理服务平台」（beian.mps.gov.cn）办理，免费 | 【硬】公安部 33 号令 / 【经验】审核 1–10 个工作日 |

### 3.3 微信个人主体小程序的硬限制（决定「能不能做成 App」）

| 限制 | 内容 | 影响 | 性质 |
|---|---|---|---|
| **web-view 不可用** | 官方组件文档：「承载网页的容器……**个人类型的小程序暂不支持使用**」 | **H5 套壳进个人小程序 = 不可行**；必须原生页面（本项目已原生重写，正好绕开） | 【硬】 |
| 微信认证 | 「**个人类型账号暂不支持微信认证**」；未认证不影响发布上架，但「被搜索、分享」能力需认证（可通过第三方服务商代认证，约 30 元/次【经验】） | 早期用户只能靠扫码/分享进入，搜索不到 | 【硬】/【经验】 |
| 微信支付 | 已认证账号才可使用微信支付；个人无法自行认证 ⇒ **个人小程序不能做支付** | 本项目非商业，无影响 | 【硬】推论 |
| 隐私保护指引 | 自 2023-09-15 起，处理用户个人信息的小程序须**主动向平台同步隐私保护指引**，否则隐私接口不可调用 | 必须配置，否则 `setClipboardData`/相册/选图/订阅消息等会异常 | 【硬】 |
| 服务器域名 | 小程序只能请求**已配置域名**，且「**域名必须经过 ICP 备案**」、仅 HTTPS、不能用 IP/localhost | 现有 API `tool-d4gosudok46e0e081.api.tcloudbasegateway.com` 是腾讯域名（应已备案，**待后台实测**）；最稳是等自有域名备案后改用 `api.furina.fun` | 【硬】 |
| 个人类目白名单 | 「教育服务」下个人仅开放 **教育信息展示**（无资质要求，但不得含视频/直播/课程销售）；「工具」下开放办公、信息查询、预约/报名、日历、计算器、健康管理、备忘录等 | 本项目应选「工具-办公/信息查询」+「教育-教育信息展示」双类目 | 【硬】 |

### 3.4 其他硬约束

- **Apple 中国区**：2023-09-01 起 MIIT 要求所有新 APP 上架前完成 ICP 备案；Apple 于 2023-09-29 更新 App Store Connect 支持文档要求提供 ICP 备案号【硬，媒体/开发者论坛转述】。审核条款 4.2（最低功能）、1.2（UGC）、5.1.1（隐私/账号删除）对 WebView 壳不利【硬】。
- **国内安卓商店**：华为审核 Checklist 明确「**APP 备案**」为必查项（单机/境外应用除外），且要求备案主体信息、应用名称、包名与在架信息一致；小米要求《计算机软件著作权证书》或《APP 电子版权认证证书》**以及 ICP 证明**；vivo 要求个人开发者上架所需资质（软著、APP 备案）**本人持有**【硬/官方文档 + 经验】。
- **教育 APP 备案**（教育部 2019《教育移动互联网应用程序备案管理办法》）：按「提供者备案 + 使用者备案」管理，提供者通常是**企业/社会机构/学校**，个人无法完成提供者备案【硬/办法原文 + 经验判断】。⇒ **个人主体把 APP 定位成「教育类」上架，基本走不通**。
- **个人信息保护**：处理敏感个人信息需**单独同意**并说明必要性（PIPL）；体测数据、学号属于需要重点说明的数据；小程序/APP 必须有隐私政策 + 数据删除通道【硬】。

## 4. 路线 A–F 逐条比较

> 每条统一六问：**能否满足「可备案」/ 前置件 / 技术改造量 / 周期 / 费用 / 风险**。周期从 2026-11-05 起算，含等待期；费用为增量。

### 路线 A：微信小程序为主（已开发完成，补备案 + 发布）

**结论：✅ 完全满足「可备案」，且是当前最短路径。**

| 维度 | 评估 |
|---|---|
| 能否满足可备案 | ✅ 取得**小程序备案号**（工信部 APP 备案体系内），发布后自动展示；不需要先有网站 ICP 备案 |
| 前置件 | ① 小程序类目（工具-办公/信息查询 + 教育-教育信息展示）【约 1–7 工作日审核】；② 用户隐私保护指引（后台配置，按实际收集项：学号/姓名、剪贴板、相册写入、选图/选文件、订阅消息）；③ 小程序备案（身份证 + 人脸核身 + 12381 短信）；④ 服务器域名配置（CloudBase 网关域名或备案后自有 `api.furina.fun`）；⑤ 代码上传 + 提审 + 发布 |
| 技术改造量 | **≈ 0.5–2 人日**：隐私弹窗/隐私授权流程补齐（若微信平台默认弹窗无法覆盖）、去掉/收窄「原始 QQ 消息」展示、小程序内不出现外链/二维码引流、审核用测试身份确认（已上云）。**H5 红线完全不受影响**（小程序不碰构建链，也不改 H5） |
| 周期 | **乐观 3 周 / 中位 4 周 / 保守 6 周**。分解：类目 1–7 天 ∥ 隐私指引 0.5 天 → 备案提交后平台初审 1–2 天 + 短信 1 天 + 管局 1–20 工作日（经验中位 3–7 工作日）→ 提审 1–7 工作日 → 发布 |
| 费用 | **¥0**（备案/发布免费）；可选个人认证 30 元/次【经验】；CloudBase 个人版与域名是既有支出 |
| 风险 | ① 类目与内容不符被驳回；② 隐私指引/隐私接口报错；③ 服务器域名备案校验不通过（第三方域名被拒 → 改自有备案域名）；④ 通知内容涉及抓取第三方群消息 → 审核问询；⑤ 个人主体不能 web-view，若后续想 H5 复用只能走「同一套云端数据、双端原生」而非套壳（现状即如此） |

**官方依据**：微信小程序备案操作指引、小程序开放的服务类目、网络能力文档（服务器域名必须 ICP 备案）、web-view 组件文档（个人不支持）。

| 维度 | 评估 |

## 6. 推荐

### 6.1 三个目标各自的推荐

| 目标 | 推荐 | 理由 | 拿到什么 |
|---|---|---|---|
| **最快合规上线** | **A（微信小程序）** | 备案与发布全流程在微信平台内闭环，3 周可上线；不需要先等网站备案 | 小程序备案号 + 已发布小程序 |
| **最小成本** | **A（微信小程序）** | 备案/发布免费，复用现有 CloudBase 与域名，增量 ≈ ¥0–30/年 | 同上 |
| **最像 App** | **A（微信小程序）**，次选 B+PWA | 原生 tabBar、页面转场、订阅消息、转发/朋友圈、离线缓存都已具备；PWA 在微信内装不了 | 原生 App 观感 |

### 6.2 综合推荐（执行方案）

> **A 先行 + B 补底座：以微信小程序作为「主 App 形态」，同时用现有 CloudBase 个人版环境把 `furina.fun` 的 ICP 网站备案办下来。**

```
第一阶段（W1–W4）：小程序备案 → 提审 → 发布        ← 最快拿到「合规 App」
第二阶段（W2–W6）：furina.fun 网站 ICP 备案 → CloudBase 静态托管大陆化 → 备案号悬挂 → 公安备案
第三阶段（W6–W12，可选）：软著 → 安卓 WebView 壳 + APP 备案 → 商店上架（类目选「工具」，准备被拒预案）
第四阶段（可选）：PWA 增强（需用户同意拆多文件）；iOS 暂缓；其他小程序平台不做
```

**为什么不是「先做网站备案再做小程序」**：小程序备案不依赖网站备案，先做小程序能最快拿到备案号与可用产品；网站备案的价值在于①给 H5 一个合法的大陆落点（速度/稳定）②给未来安卓/iOS 的 APP 备案提供域名与主体基础③让「tool.furina.fun」这个品牌域名不再处于灰色状态。

**为什么不让 H5 直接「套壳」进小程序**：个人主体小程序**不支持 web-view**【硬】，这条路物理上不存在；项目已原生重写 18 页，反而是最优解。

**为什么 iOS 不建议现在做**：需要 Mac（当前 Windows），$99/年，4.2 对 WebView 壳几乎必拒，投入产出比最低。

## 7. 前置依赖顺序、时间表与关键路径

### 7.1 前置依赖顺序（硬顺序，不可跳步）

```
[域名] furina.fun 已注册 + 实名(本人) + 有效期>45天
   │
   ├─→ [小程序线] 类目选择 → 隐私保护指引配置 → 小程序备案(主体/负责人/人脸/短信) → 备案号 → 服务器域名配置 → 代码上传 → 提审 → 发布 → 备案号自动展示
   │                                                   ▲
   │                                        （备案不依赖网站备案，可独立跑）
   │
   └─→ [网站线] CloudBase 环境确认(个人版/有效期>6月/固定IP) → 腾讯云备案提交(网站+域名)
                    → 管局通过 → 绑定自定义域名+证书 → 切解析 → 首页悬挂备案号
                    → 上线后 30 日内 公安联网备案
                    → （后续）软著 → APP 备案 → 安卓商店上架（共用同一主体与域名）
```

**几个容易踩的顺序坑**：
1. **域名实名信息同步需要 2–3 天**才进工信部库：如果最近改过实名/过户，先等 3 天再提交备案【硬，阿里云/腾讯云口径】。
2. **小程序备案不要求先有网站备案**，但小程序「服务器域名」要求域名已 ICP 备案——当前用腾讯云网关域名可先跑，**长期建议改成备案后的 `api.furina.fun`**以消除校验风险。
3. **备案通过前网站不得对外提供服务**（福建管局明确「未备案域名严格要求不允许访问」）：现有香港站是境外接入、不受该条直接约束，但一旦用同一域名提交备案就要处理「备案期仍在访问」的观感风险（见 7.3）。
4. **公安备案必须在网站上线后 30 日内**，别忘。
5. **APP 备案的应用名称/包名/主体**必须与在架信息一致，改名就要重备（安卓阶段再考虑）。

## 附录 B：一句话回答「现在到底合不合法」

> 当前 H5 托管在香港、未做 ICP 备案：**不违反境内接入备案义务**（备案义务针对境内接入服务），但**拿不到备案号**，因此无法满足小程序/APP/商店的备案校验，也无法作为「可备案 App」交付；同时通知内容来自 QQ 群抓取、体测属敏感个人信息，**这两点是当前最现实的法律/平台风险**，与是否备案无关，应优先整改（§9 R7/R8）。
