## 0. 一页结论

| 问题 | 结论 |
|---|---|
| 现在能直接备案吗？ | **不能。** 香港 OSS 没有内地接入资源，云厂商无备案服务码可受理；且 5 项阻断级合规缺口未清零 |
| 最快多久拿到「可备案 App」？ | **微信小程序 3–5 周**（乐观 11 月底、稳健 12 月上旬发布）；**网站 ICP 备案**建议用 2027 寒假窗口（1/11 起停机，2 月初完成）；安卓 APP 备案再 +4–8 周（可选） |
| 要换域名吗？ | **不用。** `.fun` 是工信部 2017 年批复后缀（信管函〔2017〕432 号），在阿里云官方可备案清单内；域名注册商为阿里云（已批复机构） |
| 要买服务器吗？ | 建议买 **1 台阿里云轻量应用服务器（38–99 元/年）**：既拿备案服务码，又直接托管静态站；备选 CloudBase 静态托管（需「个人版 + 剩余有效期 ≥6 个月 + 云托管固定 IP」，条件待后台实测） |
| 备案主体？ | **个人（你本人）**。2008-07-08 出生，2026-11 已满 18 周岁，福建身份证 → **不需要**居住证、监护人材料 |
| 小程序类目 / 备案服务内容？ | **工具（办公 / 信息查询）**；**不要选教育**（个人备案对教育类「不建议选择」） |
| 安卓 App 做不做？ | **可做，但主路径是「官网 APK 分发 + APP 备案」**，不把国内应用商店当主路径（纯 WebView 套壳被拒概率高） |
| 首年增量预算？ | **约 ¥280–340**（CloudBase 续费 ≈¥239 + 轻量服务器 ≈¥38–99）；备案、小程序备案、软著全免费；域名 2029 年到期暂无需续费；iOS 暂缓（$99/年 + 必须 Mac） |
| 最大风险是什么？ | **不是备案驳回，是这三件**：① QQ/微信群消息抓取后二次分发（阻断级，必须改）；② 个人信息「告知—同意—删除」链缺失（阻断级）；③ 产品可能被认定为「教育移动应用」（需书面咨询 + 定位规避） |

> **一句话**：备案是流程问题，2–6 周能办完；真正决定成败的是三件事——**群消息来源合不合法、个人信息同意与删除做没做、这个产品到底算不算「教育移动应用」**。

## 1. 目标、范围与验收口径

### 1.1 什么叫「可备案 App」（三层 + 一层可选）

| 层 | 名称 | 谁发 / 谁办 | 本项目对应 | 费用 |
|---|---|---|---|---|
| ① | **网站 ICP 备案号**（域名层） | 省通信管理局，经接入商（阿里云/腾讯云）提交 | `furina.fun` → 首页底部悬挂「闽ICP备xxxxxxxx号」 | 免费 |
| ② | **小程序备案号**（应用层，属工信部 APP 备案体系） | 省通信管理局，经微信平台代提交 | 微信小程序 → 发布后自动展示在「更多资料」页 | 免费 |
| ③ | **公安联网备案号** | 属地公安机关（beian.mps.gov.cn） | 网站开通后 **30 日内**办理 | 免费 |
| ④（可选） | **安卓 APP 备案号** | 省通信管理局，经接入商/分发平台提交 | 安卓 APK 的独立备案（与①③并列，不共用） | 免费 |

**「可备案 App」在本项目 = ①+②+③ 齐全；做安卓则再加 ④。**

### 1.2 目标状态（Definition of Done）

- [ ] 小程序：已备案（有备案号）→ 已提审通过 → 已发布上线，真机全流程可用
- [ ] 小程序：隐私保护指引与实际接口一致；隐私政策/用户协议可打开；可导出/删除个人数据
- [ ] H5：已 ICP 备案并悬挂备案号；强制 HTTPS；隐私政策/用户协议/同意勾选/数据管理页齐全
- [ ] H5：通知管道已完成合规改造（无未经授权的群消息二次分发、敏感信息已脱敏）
- [ ] 云端：测试身份已清理；本人数据可删除；有保留期限与清理任务；RLS/DDL 已入库可复现
- [ ] 公安联网备案完成（网站上线 30 日内）
- [ ] 安卓（若做）：软著 + APP 备案 + 官网分发（或商店上架）
- [ ] 文档：隐私政策、用户协议、个人信息处理清单、PIA、应急预案、备案台账（各 1 份）

### 1.3 不做清单（红线）

- ❌ 不改 `me.furina.fun` 的代码/Bucket（另一站点，红线）；备案期如需暂停其访问必须单独确认
- ❌ 不引入 npm/构建链改造 H5（单文件、零外部请求保持不变；安卓壳是独立工程，不算）
- ❌ 不把名单/学号/手机号/宿舍号写进公开 HTML、小程序包体、导出图片
- ❌ 不买「备案加急 / 包过 / 代上架」服务（官方无此通道，账号风险高）
- ❌ 不做「审核模式/演示模式」骗取审核（按项目既定要求）
- ❌ 不把班级数据发给境外 AI/服务；AI 摘要保持「内部可选」或关闭
- ❌ 不在未完成告知同意前收集/上传任何个人信息

## 2. 现状体检（结论版）

### 2.1 资产与能力盘点

| 资产 | 现状 | 合规含义 |
|---|---|---|
| H5 站点 | `tool.furina.fun`，阿里云 OSS 香港，单文件、零外链、Let's Encrypt | 境外托管**不适用**境内 ICP 备案义务，但拿不到备案号；是「可备案 App」的最大缺口 |
| 微信小程序 | 个人主体 `wx3df9869d229b96c4`，18 页原生、无 web-view/支付/外链，v2.0.0 源码完成，**未上传/未发布** | 技术就绪度高；缺备案、类目、隐私指引、服务器域名 |
| 后端 | 腾讯云 CloudBase 个人版 `ap-shanghai`，PostgreSQL + PostgREST + RLS + 班级 token | 数据在境内（加分）；但**环境 2026-11-10 前后到期**，需确认续费；RLS/DDL 仓库漂移 |
| 域名 | `furina.fun`：阿里云注册商、阿里云 DNS、2029-06-17 到期 | 注册商已批复、后缀可备案；需核对**域名实名 = 本人** |
| 身份体系 | 学号 + 姓名 → `class_verify` → 30 天 token；70 人真实名单 | 个人信息；弱凭证（无二因子/限流/撤销），需加固 |
| 内容来源 | 本机 `C:\briefdesk` 采集 QQ/微信群消息（含 OCR）→ 云端 `notices` → 全班可见 | **最高风险，阻断级**（详见 §5 Phase 0） |

### 2.2 五个阻断项（不清零不能提审/备案）

| ID | 现状 | 为什么阻断 | 整改动作 | 工作量 |
|---|---|---|---|---|
| **B-1** | H5 身份页直接收集学号+姓名并上传，**无隐私政策/用户协议/同意**；小程序仅说明卡片、无同意 | 违反个保法 13/14/17/30 条；小程序审核直接驳回 | 写《隐私政策》《用户协议》；两端口收集前「已阅读并同意」勾选 + 可打开全文；提供导出/删除 | 2–3 人日 |
| **B-2** | 通知来自 QQ/微信本地库**非官方抓取**并写云端二次分发；审计快照 45 组中 39 组含发送人姓名、**11 组含 11 位手机号**、5 组含 OCR 名单，多为 `all` 全班可见 | 他人个人信息无同意基础；违反平台协议；可被举报/下架/追责 | 立即停止「自动抓取→上云→公开展示」；改为**人工确认后发布 + 上传前脱敏**；清理历史敏感通知；群内公告告知 | 1 人日（止血）/ 5–10 人日（重构） |
| **B-3** | 无网站 ICP 备案；小程序 request 域名 `tool.furina.fun` 未备案；静态托管在香港 | 无法满足「可备案 App」；小程序正式版跨域请求被拦 | 小程序备案（先）+ 网站 ICP 备案（后，寒假窗口）+ 小程序切已备案域名 | 1–2 人日准备 + 管局等待 |
| **B-4** | 云端仍有**测试身份**（`is_test`），凭据写在交付说明 | 拿到文档者可登录看 `audience=all` 全班数据 | 上线/提审前执行清理 SQL（删 `class_sessions` + `class_ids` 测试行）；交付文档中的凭据作废 | 0.1 人日 |
| **B-5** | 小程序后台隐私指引只声明「学号+姓名」，但实际用了相册/相机/文件/写入相册；代码无隐私授权适配 | 真机可能 `errno 112`；审核要求整改 | 后台隐私指引逐项勾选 + 代码接入微信隐私授权（默认弹窗或 `requirePrivacyAuthorize`），真机回归 | 0.5–1 人日 |

### 2.3 十二项高风险（摘要）

| ID | 问题 | 关键动作 |
|---|---|---|
| H-1 | 通知未脱敏（手机号/姓名/OCR 名单）对全班可见 | 上传前正则脱敏 + 前端不显示发送人实名 + 清理历史 |
| H-2 | H5 退出身份**不清主数据桶**（70 人名单含学号残留）；无数据管理页 | 退出即删 `zq_tools_v2_<sid>` 等全部本机数据；新增数据管理页 |
| H-3 | 云端 `visits/feedback/marks/userdata/fitrecs` 无 DELETE、无保留期限 | 新增本人删除 RPC + 保留期清理任务 |
| H-4 | `class_members` 向所有人下发 70 人学号；visits 存 sid+name+设备码；H5 反馈仍收 QQ/微信 | 名单去学号（管理员另开接口）；visits 匿名化；反馈去联系方式 |
| H-5 | 学号+姓名即凭证；无失败限流/撤销；token 30 天明文；401 不回门禁 | 限流 + 服务端失败告警 + 短 TTL/刷新 + 401 回门禁 |
| H-6 | H5 线上公开 HTML 含 **2 个真实学号**（legacy 迁移硬编码） | 删除硬编码，改「当前账号」通用逻辑，重新部署 |
| H-7 | 本机 `C:\briefdesk\secrets` 明文集中（DeepSeek key、管理员 token、22 个微信库密钥、ECS 私钥） | 迁 DPAPI/凭据管理器 + 轮换 + 目录 ACL |
| H-8 | RLS/DDL 仓库漂移，旧 SQL 误跑会把权限打回公开 | 从现网导出权威 schema 入库；废弃 SQL 标 DEPRECATED |
| H-9 | 非官方 QQ/微信客户端读本地库（qqflow/weflow + 库密钥解密） | 与 B-2 同批停用；工具链删除或仅本机个人用途 |
| H-10 | HTTP 明文可访问（无 301/HSTS） | OSS 强制 HTTPS（或迁移后 nginx 301+HSTS） |
| H-11 | 作业/通知/反馈 UGC 无内容审核 | 小程序接 `msgSecCheck`；H5 加敏感词过滤 |
| H-12 | 群消息原文（含手机号/姓名）直接发 DeepSeek，无脱敏/告知 | 发送前脱敏 + 隐私政策披露；或仅本地模型 |

> 完整审计（含证据行号、11 项中风险、9 项低风险、12 项待确认）见 `web\_compliance\audit_current_state.md`。

### 2.4 已经做对的部分（保留）

- 零外部依赖/SDK/埋点；H5 只请求 CloudBase 一个域名；小程序无 web-view/定位/通讯录接口
- 前端无高权限密钥（仅 publishable key）
- CORS 精确白名单（实测 204/403）；匿名 SELECT 全部返回空（RLS 生效）
- 身份未通过前不请求班级数据；导出图不含学号/手机号，有水印/编号/AI 摘要标识
- 小程序「数据与隐私」页已具备导出/清云端/清本机雏形（H5 需对齐）
- 小程序退出身份清全部缓存；`sitemap.json` 全站 disallow

审计发现 `web\tools\index.html` 在 2026-11-05 22:23–22:38 被**并发会话改写 3 次**（468,856 → 454,498 → 468,856 B）。整改前必须：

## 4. 路线决策（含取舍）

### 4.1 总路线：四阶段 + 一个可选

```
Phase 0 合规止血（W1，11/06–11/12）
   ├─ 隐私政策/用户协议/同意 + 数据管理页
   ├─ 群消息管道止血（停止自动上云/脱敏/人工确认）
   ├─ 测试身份清理、真实学号删除、HTTPS 强制
   └─ 材料与账号核对（域名实名 / CloudBase 续费 / MP 后台 / 备案入口）
        │
Phase 1 小程序备案 → 提审 → 发布（W2–W5，目标 12 月上旬上线）
        │
Phase 2 网站 ICP 备案 → 大陆托管 → 备案号 → 公安备案（W10–W13，寒假窗口 1/11–2/04）
        │
Phase 3 安卓 App（可选，12 月–3 月）：软著 → WebView 壳 + 原生化 → APP 备案 → 官网分发
        │
Phase 4 长期合规运营（3 月起）：年度审计、保留期清理、变更备案、iOS/PWA 评估
```

**为什么小程序先行**：小程序备案不依赖网站备案，是拿到「可备案 App」的最短路径；个人主体不支持 web-view，而项目已原生重写 18 页，正好绕开。

**为什么网站备案放寒假**：网站首次备案期间域名不得开放访问（福建管局明确），而小程序发布后可以承接用户；寒假（1 月中旬–2 月上旬）使用量最低，停机 2–3 周影响最小。

**为什么备案要串行**：微信官方 FAQ 明确「不支持在不同平台同时提交备案申请」，否则会被判「主办者冲突」。顺序：**先小程序备案，完成后才提交网站 ICP 备案**。

### 4.2 决策 A：网站托管放哪（三选一）

| 方案 | 做法 | 备案资源 | 成本 | 优点 | 缺点/风险 | 结论 |
|---|---|---|---|---|---|---|
| **A1 阿里云轻量应用服务器（推荐）** | 买 2 核 2G 轻量（38–99 元/年），nginx 托管静态文件 | 轻量实例自带备案服务码 | 38–99 元/年 | 确定性最高；备案服务码现成；静态站足够；可强制 HTTPS/HSTS/301；部署=scp+nginx | 需维护一台服务器（nginx/证书）；需改 `sync_tools.py` 目标 | ✅ **主方案** |
| A2 腾讯云 CloudBase 静态托管 | 文件传 CloudBase 静态托管，绑自定义域名 | 云开发环境（个人版+、有效期≥6 月、云托管固定 IP） | 含在 CloudBase 套餐 | 与后端同厂商；无需管服务器 | 备案条件需后台实测（个人版能否开云托管固定 IP 不确定）；部署链路要重写（CLI/API） | 备选（若 A1 不可用/不想管服务器） |
| A3 阿里云 OSS 大陆 + CDN | 新建大陆 Bucket + CDN + 证书 | 需另买 ECS/轻量拿备案服务码 | OSS 流量费 | 零运维 | 备案资源与托管不一致的核验风险；CDN 配置复杂 | ❌ 不推荐 |

> 无论 A1/A2，**后端继续留在腾讯云 CloudBase（上海）不动**，只需在备案完成后给 HTTP 网关绑定 `api.furina.fun`（或分别绑 `api.` ）、更新小程序服务器域名。

### 4.3 决策 B：小程序后端域名怎么走

| 阶段 | 方案 | 说明 |

| **Phase 1（现在–12 月）** | 继续用 CloudBase 网关域名 `tool-d4gosudok46e0e081.api.tcloudbasegateway.com`（腾讯自有、已备案） | 微信能配、能请求；但**腾讯官方口径是「默认域名仅开发测试，生产必须绑已备案自定义域名」** → 作为过渡可接受，需真机实测 |

### 4.4 决策 C：群消息管道怎么改（三方案）

| 方案 | 做法 | 合规性 | 工作量 | 结论 |
|---|---|---|---|---|

### 4.5 决策 D：备案顺序与停机窗口

- **顺序**：小程序备案（11/10 提交）→ 通过 → 提审 → 发布 → **网站 ICP 备案（1/11 提交）** → 通过 → 迁站 → 恢复访问 → 公安备案 → 小程序切 `api.furina.fun`
- **网站备案停机窗口**：建议 **2027-01-11 至备案通过（预估 1–3 周）**，期间：
  - 暂停 `tool.furina.fun` 解析（DNS 暂停或指向维护页均不行——「不得开放访问」，直接暂停解析最稳）
  - 班群公告：H5 暂停，改用小程序
  - `me.furina.fun`（同一主域名的另一站点）：**是否同步暂停需你确认**（红线：不得改它；暂停 DNS 不等于改站）
- **备选（零停机）**：新注册一个 `.cn` 域名专门备案（约 ¥40/年），旧域名不动；通过后新域名承载，后续再接入旧域名。代价：品牌/二维码/水印迁移。
