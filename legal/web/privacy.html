01一、定义与适用范围

本政策是网页端（浏览器，含手机、平板和桌面浏览器）（以下简称“本端”）的隐私政策，由 陈子麒 以个人开发者身份发布。本政策适用于本端的身份核验、班级工具、跨端同步、通知提醒、诊断、反馈、PPT、文件传输等全部功能，以及本端在本政策生效期间处理个人信息的活动。

本政策不适用于：学校教务/统一认证、学信网、快递、微信、OPPO、华为、Microsoft Office、浏览器等第三方独立提供的产品/服务。您使用这些第三方时，应阅读其各自的隐私政策/用户协议；本站不控制第三方的处理行为。

1.1 本端功能与边界

本端是班级内部辅助工具，不是学校官方平台，不提供公开注册、教育培训、新闻、社区、支付、广告、直播或电商服务。本端仅面向班级官方名单内的成员；非本班人员无法通过身份核验。

1.2 主要定义

个人信息
以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
敏感个人信息
一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。
处理
包括个人信息的收集、存储、使用、加工、传输、提供、公开、删除等。
处理者
自主决定处理目的、处理方式的组织、个人；本政策中指 陈子麒（个人开发者）。
受托处理
接受处理者委托，按照约定处理个人信息的主体；本政策中指腾讯云、阿里云等云服务商。
删除
从我们的业务系统中移除个人信息，使其不能被访问、检索；备份/日志中的副本按备份周期滚动覆盖。端内“清除云端”如为覆盖/置否/归档，属于逻辑清除，不等同于物理删除。
匿名化
个人信息经过处理无法识别特定自然人且不能复原的过程；匿名化后的信息不属于个人信息。

03三、我们处理哪些信息

我们遵循最小必要原则：只处理实现班级工具功能所必需的信息，不收集与功能无关的信息，不进行广告画像，不出售个人信息。完整字段、来源、存储和保留期见附件 A。

3.1 身份与班级组织信息

学号、姓名、班级身份令牌、签发/到期时间；座号、班委职务/徽章、团员身份、管理员标识。学号 + 姓名仅用于与班级官方名单比对；页面和导出图不展示学号（电费页仅展示本人关注宿舍的规范楼栋 + 房间号 + 电量，且不导出）。

3.2 班级共享内容

班级名单、作业、通知、课表、电费/水量、投票、PPT、文件等。它们可能由班委/管理员整理，或来自班级公开群、学校教务快照。通知可能包含发送人昵称、角色、文本、图片、附件、OCR 文本等；我们要求管理员在发布前去除手机号、身份证号、学号等不必要的个人信息，但无法保证每条内容都完全脱敏。我们会在班级群公告/本页说明通知整理范围，不采集私聊；如您是内容中的当事人且不希望被展示，请通过邮箱/反馈申请删除。

3.3 您的操作与偏好

作业完成、通知已处理/置顶、工具栏顺序与工具页顺序、体测录入与历史、抽签/分组参数与名单、点名名单与到·假、隐藏项、课表与提醒偏好、昵称、关注宿舍（电费）、抄表记录（水量）、投票选择、PPT 上传、文件传输、反馈、诊断上报等。网页端与小程序、安卓、鸿蒙、电脑端按同一账号同步（以各端实际支持为准）。

3.4 设备、日志与诊断

为保障安全、排查故障和适配屏幕，本端可能处理：设备/系统/浏览器或 WebView 版本、屏幕尺寸、内存/存储、网络类型、时钟偏差、接口延迟、异常摘要、崩溃/错误码；云服务商可能记录 IP、时间、请求路径、状态码、User-Agent 等网络日志。设备信息按最小化字段采集；日志不记录 token、学号、姓名、宿舍号。

3.5 权限与系统能力

本端只申请实现功能所需的权限；未列出的权限（定位、通讯录、短信、通话记录、相机、麦克风、生物识别等）不申请。完整权限见附件 B。

3.6 第三方来源

微信小程序端的 openid 来自微信云开发；安卓端的 OPPO openID/authCode 来自 OPPO 账号服务；鸿蒙端的华为 openID 来自华为 Account Kit；通知摘要可能由 DeepSeek API 辅助生成；课表可能来自学校教务快照。我们只接收实现功能所必需的最小字段。

3.7 我们不主动收集的信息

身份证号、人脸/指纹/声纹、银行卡、精确位置、通讯录、短信、通话记录、剪切板历史、相册全量、麦克风、健康平台数据、宗教信仰、医疗病历等。若您主动上传的文件中包含这些信息，由您自行负责；我们可能要求删除或拒绝展示。

3.8 本端特别说明

1. 浏览器本地存储

网页端使用以下浏览器本地能力。它们只保存在当前浏览器/设备上，不上传到与本站无关的第三方：

  • localStorage：身份令牌与姓名 / 学号（zq_class_identity）、工具与页面偏好（zq_tools_v2_<sid>）、同步缓存（zq_udcache_*）、勾选缓存（zq_marks_cache_*）、提醒与外观偏好等。
  • IndexedDB：通知列表等较大的本机缓存，用于减少重复请求和离线展示。
  • 浏览器缓存 / Service Worker：本站当前不注册用于后台推送的 Service Worker；如浏览器自身缓存静态资源，可在浏览器设置中清除。

本站不使用广告 Cookie、跨站跟踪 Cookie 或第三方统计脚本。CloudBase 网关可能为安全目的使用必要的会话/安全机制，具体以腾讯云服务条款为准。

网页端的提醒依赖浏览器 Notification 权限和页面打开状态。您可以在提醒设置中拒绝或关闭；关闭后仅影响提醒，不影响其他功能。页面关闭、浏览器被系统回收或设备休眠后，网页端无法保证继续提醒。

3. 演示（PPT）与跨境存储

网页端支持上传 PPT、由本机转换机转换为分步图片/视频/PDF/兼容版，并下载。PPT 源文件、转换产物和单独抽取的音视频存放在阿里云 OSS 香港（oss-cn-hongkong），属于向香港传输并存储。OSS Bucket 为公共读：链接不可枚举，但持有链接的人可以访问。请勿上传含身份证、成绩单、病历、手机号、住址等敏感信息的 PPT。首次上传前，网页端应以单独弹窗取得您的单独同意；如不同意，请不要使用 PPT 功能。

4. 文件传输、大屏与互联

文件传输使用阿里云 ECS 的临时空间，文件自上传完成起 72 小时自动删除；下载链接为短时签名链接。大屏会把抽签、投票、名单、PPT、计时等内容展示在教室/活动现场；文件互联只允许同一班级账号的设备互见，但大屏现场人员仍可能看到屏幕内容。请勿在大屏展示敏感个人信息。

5. 诊断信息

诊断页会读取浏览器/设备的基础信息（平台、系统、浏览器/WebView 版本、屏幕、内存、存储、网络类型、时钟偏差）和接口延迟，用于判断故障。诊断报告会脱敏（不展示 token、学号、姓名），但已认证的班级成员可以在诊断页看到脱敏后的服务健康与设备检查结果。您可以在诊断页选择是否上报异常。

6. 网页端不收集的信息

网页端不主动读取通讯录、短信、通话记录、精确定位、相册全量、摄像头、麦克风、剪贴板历史或生物识别信息。您主动选择文件、上传 PPT、复制导出文本时，才会读取对应内容。

05五、敏感个人信息

本端可能处理以下敏感个人信息。我们会在处理前以单独弹窗/勾选/明确提示等方式向您告知必要性、对您的影响，并取得单独同意；您拒绝仅影响对应功能，不影响身份核验和其他工具。您可以随时撤回同意，但撤回不影响撤回前已进行的处理。

5.1 体测健康数据

身高、体重、肺活量、50 米、坐位体前屈、立定跳远、引体向上/仰卧起坐、长跑、总分/等级等，用于国标算分、等级和历史记录。属于医疗健康类敏感个人信息。数据原则上仅本人可读写；不导出给他人；您可在体测历史删除或邮件申请删除。拒绝提供仅影响体测功能。

5.2 教务账号/密码（可选）

教务账号/密码仅限本人使用、不得共享。各端处理方式不同：

  • 安卓端：如您选择保存密码，密码用 Android Keystore AES-256-GCM 加密后仅存本机；不上传、不同步、不写日志。WebView 打开学校官方页面；退出/清除登录会删除密文和 Cookie。
  • 鸿蒙端：可选 Asset Store 本机加密保存；如使用“个人课表登录”，密码经 PGP 加密后暂存云端任务队列，由管理员本机转换程序解密并向学校系统提交；明文不写入数据库/日志。
  • 网页端/微信小程序端：如使用个人课表登录，密码经 PGP 加密后暂存云端任务队列，由管理员本机转换程序解密并向学校系统提交；提交后任务清理；明文不落 localStorage/数据库/日志。
  • 电脑端：原生端不收集、不保存教务密码；如打开网页登录入口，适用网页端的规则。

教务系统可能因共享账号、频繁登录、验证码/风控限制账号；请遵守学校规定。因学校规则导致的限制/封禁，由学校处理，本站不承担责任。

5.3 特定身份/班级组织信息

10十、安全保护

10.1 技术措施

  • 正式环境使用 HTTPS/TLS 传输；云端接口使用班级 token + 行级权限（RLS）校验，前端不持有高权限密钥。
  • 身份 token 约 30 天；退出/失效即清理本机会话；安卓 allowBackup=false；电脑端 DPAPI；安卓 Keystore；鸿蒙 Asset Store。
  • 日志脱敏：不记录 token、学号、姓名、宿舍号、密码；诊断字段最小化；错误上报做掩码。
  • 最小权限：管理员仅访问维护所需数据；云端表按本人/管理员/班级成员分级授权；投票等敏感表不开放匿名直连。
  • 依赖最小化：网页端零外部统计/广告/字体；原生端不接第三方统计/广告 SDK。

10.2 组织措施

仅管理员/必要维护人员可接触云端数据；要求保密；定期检查权限、日志、备份和第三方服务；发现漏洞/事件时及时修复。我们会对受托方（云服务商）做基本安全评估，但无法控制其全部内部行为。

10.3 您的配合

请使用锁屏密码/系统账户保护设备；不要在共用设备保存教务密码；不要截图/转发 token、身份页、班级名单；发现账号被冒用、token 泄露、设备丢失，请立即退出登录、修改学校密码（如适用）并联系我们。

10.4 安全事件

如发生或可能发生个人信息泄露、篡改、丢失，我们会立即采取补救措施，评估影响，按法律要求向监管部门报告，并通过班级群/邮件/页面通知受影响的用户；必要时建议您修改学校密码、解绑 OPPO/华为账号。我们不会隐瞒事件，但也不会在未核实前发布不实信息。
