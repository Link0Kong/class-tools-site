安卓端（Android 原生 App，包名 com.furina.classtools）

  • 原生 App：安卓端是 Kotlin + Compose 原生应用；身份令牌、班级缓存保存在应用私有目录，系统云备份已关闭。

电脑端

Windows 0.1.0（WinUI 3 里程碑版）

电脑端（Windows 原生客户端，ClassTools.exe）

  • 仅 Windows 桌面：电脑端是 WinUI 3 / .NET 原生应用，仅支持 Windows 10/11 x64；不是网页套壳，不内嵌 WebView。
