我是谁

ABOUT

我是陈子麒，福建漳州人。2026 年从福州七中毕业，现在在福建中医药大学人文与管理学院读信息管理与信息系统。高中我读的是物理·生物·地理，可比起背书，我一直更擅长动手。

我的时间大多花在两件事上：把重复的活儿交给脚本，和把喜欢的东西做到自己满意。游戏日常、学校打铃、班级工具、记账签到——凡是每天要重复点一遍的，我都想让它自己跑起来；凡是能做得好看一点的，我就不想凑合。

我不太会说漂亮话。班里的考场座位表是我排的，班会的记录是我写的，同学的作业清单是我做成图发出去的。这些事都很小，但我做得很认真——因为一个集体里，总得有人愿意把小事做到底。

「我想成为一个传递温暖的人。」——这句话我写在十六岁，到现在还算数。

竞选演讲稿全文约 490 字 · 上台就说这些

大家好。我是陈子麒，一名共青团员。今天我想竞选的岗位，是团支部副书记。

我不太擅长演讲，但是在做事上，我能高效、踏实、精细地完成交给我的任务。为此我也专门制作了一个自我介绍的网页，大家可以在里面看到更多我的信息，还有一些我制作的小工具。

虽然我在高中没有担任班委，但是凭借电脑技能，我依然参与了班级的很多工作：班里的考场座位表，成绩单的统计、核对，班里要用的 PPT，还有学校铃声失效时的自动铃声程序。靠着靠谱、稳定的成果，我获得了老师与同学的认可。

再说说我的学习态度。我习惯把每一步都提前排好：该预习的预习，该完成的按时完成，不拖、不糊弄。因为我一直相信——先把自己这一份做好，才有资格去带动别人。

对于副团支书，我认为辅佐团支书的工作正是我所擅长的。团费收缴、青年大学习、团组织生活、推优评议——这些事说出来都不大，但都很琐碎，而且一件都不能出错。我可以运用手上的技术，快速高效地完成这些任务，做到认真负责、不出错。

如果当选，我一定当好团支书的左右手，把这些琐碎的事一件件做扎实。即使未能选上，我的技术也随时为班级敞开——需要的时候，招呼一声就行。请大家把票投给我，谢谢大家。

校园打铃系统 · ClassBell

2025 – 一直在用

用 Windows 自带的 PowerShell 写的一套打铃脚本：按两份作息表准时响铃，全程后台静默，下课还会提醒关机。它现在还在学校的电脑上替我值班。

ring.ps1 — Windows PowerShell
PS C:\教室打铃> .\run.vbs
  • 两套作息表按星期切换，上课铃 / 预备铃 / 午休唤醒三路音源分开
  • 预备铃从文件夹里随机点歌，一轮内不重复，全放完自动重置
  • 按「离下一声铃还有多久」自适应休眠（40 分→1 分→1 秒），几乎不占 CPU
  • 当天最后一铃响完自动弹关机倒计时；互斥锁保证不会重开响两遍
