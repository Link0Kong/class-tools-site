# 校内地图 · AMap 重描版（v6）

> `campus_map_25d.html`（2.5D 预览）+ `campus_map_editor.html`（2D 布局编辑器），单文件、零外部请求。
> 本版按用户提供三张 AMap 截图重描道路/建筑/水域/绿地；坐标由 AMap master 底图反变换到原模型系。

## 本版数据
- 道路 13 条：修园西路/北路/东路、望果西路/东路、银杏西路/东路、仲景路/仲景西路/仲景东路、杏林大道、学府北路（N/SE）、学府西路；主路宽 42/34px、校内 8–14px，路线自检 51/51 栋可算。
- 建筑 50 栋：AMap 灰块轮廓重描，29 栋匹配到原楼名/楼栋号（图书馆、厚德楼、精诚楼、至善楼、五行楼、自强楼、明德楼、求真楼、修园楼、康复大楼、学生活动中心、体育馆、名师苑等），其余标为 generic。
- 水域 9、绿地 6、广场 2（AMap 广场与道路同色，识别有限）；三图配准残差 mean 0.38/0.47px，建筑仿射残差 mean 34px。
- 数据文件：`_data/preview_data.json`（旧版备份 `preview_data_v5_backup.json`）、`_data/roads_amap.json`、`_data/amap/`（master 底图、buildings_trace、features_trace、配准报告）。

## 已知限制
- AMap 拼接图未包含田径场，track 暂缺；
- 50 栋中约 21 栋未匹配旧名（部分宿舍编号体系不同）；
- 广场只提取到 2 处，棋盘/青年广场等建议在编辑器手描；
- 旧模板里写死的 POI/桥/亭位置尚未全部迁到 AMap 坐标，可能有少量错位；
- 编辑器和预览共用 `preview_data.json`，在编辑器改完导出 JSON 可回填。

## 重建
```
python make_amap_data.py   # AMap trace -> preview_data.json（模型坐标）
python build_preview.py    # -> campus_map_25d.html
python build_editor.py     # -> campus_map_editor.html
```

## 2026-11-14 修复
- **视图朝向**：2.5D 与编辑器统一按 AMap 北向显示（VIEW_ROT ≈ -0.93rad/-53°），小地图同步旋转；此前道路“位置错”主要是显示坐标系仍是旧模型朝向。
- **拖动/平移**：修正旋转后的反投影（unprojectGround / focus / 编辑器 mpos），拖动时坐标不再跳变/错位。
- **验证**：把新矢量反投影回 AMap master 做叠加（_data/amap/vector_overlay_check.png），道路落在白色路面上、建筑落在灰色块上。
