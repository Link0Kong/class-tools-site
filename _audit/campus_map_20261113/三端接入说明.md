# 校园地图三端接入说明

## 在线入口

- 班级工具站：http://121.196.47.2/
- 工具入口：首页「全部」→「地图」；课表「下一节」→「在地图看这栋楼」
- 地图 H5：http://121.196.47.2/map/campus_final_25d.html
- 地图共享状态 API：http://121.196.47.2/map/api/state

## Web（tools/index.html）

- `TOOLS` 新增 `{k:"map",n:"地图"}`，全部页自动生成卡片。
- `#s-map` 为 iframe 容器，首次进入才加载 `/map/campus_final_25d.html?embed=1`，避免首页多加载 1.2MB。
- 课表 `#tNext` 增加「在地图看这栋楼」：把 `c.room` 通过 `MAP.setRoom()` 传给地图，地图按教室号前缀定位楼栋（如 `01217` → 01 号楼/自强楼）。
- 地图内「去课表」通过 `postMessage({type:"zq-map-open",tab:"tt"})` 回到课表页；`zq-map-ready` 时父页补发目标楼。
- 地图页参数：`embed=1`（隐藏 H5 顶栏/底栏）、`b=楼名或id`、`room=教室号`、`from=校门id`。

## 小程序（mp-class-tools）

- 新页面 `pages/map/map`：原生 Canvas 俯视地图，支持单指拖动、双指缩放、点楼/搜索、楼层信息、按道路步行路线。
- 数据 `data/campus_map.js` 由最终 2.5D 数据简化生成（848×493 坐标，57 栋、97 段路、57 条从正大门出发的路线）。
- `utils/tools.js` 新增 `map` 工具与 `/images/tool-map.png` 图标；`app.json` 注册页面。
- 课表下一节卡片增加「在地图看这栋楼」，携带 `room` 打开地图；地图「去课表」返回 `pages/tt/tt`。
- 需要用户在微信开发者工具上传并发布后生效。

## Android（android-class-tools）

- `ToolCatalog` 新增 `map`（Icons.Rounded.Map），全部工具/首页可进入。
- `ui/screens/map/CampusMapScreen.kt`：Compose + WebView 加载同一 H5（`?embed=1`），原生顶栏提供「课表」回跳。
- 课表页顶栏新增「地图」。
- `network_security_config.xml` 仅对 `121.196.47.2` 放行明文（备案/DNS 恢复后改 HTTPS 域名）。
- Release APK：`android-class-tools/app/build/outputs/apk/release/app-release.apk`。
