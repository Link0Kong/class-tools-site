## 已有数据怎么迁到手机

浏览器本地草稿是**按网址隔离**的：本地 `file://` 的进度不会自动带到服务器网址。
1. 在电脑上打开原来的本地 `campus_builder.html` → 点「导出 JSON」；
2. 把 JSON 发到手机（微信文件传输助手即可）；
3. 手机打开上面的在线地址 → 点「导入」→ 选这个 JSON；
4. 之后在手机上继续编辑，草稿会存在手机浏览器本地。

> 如果你希望我先帮你把已经描的道路做接续/命名，把导出的 JSON 发我即可。

## 这一版新增

### 道路
- **一键整理路网**：把相邻道路端点吸到一起（70px 内）、在对方路上插接点、并按最近的 AMap 路名自动命名（260px 内）；离参考路网太远的标「未命名」。
- **参考路网**：蓝色虚线显示 AMap 重描的 13 条路；开关在工具栏，可对照描。
- 画路：连续点，双击 / Enter / 底部「完成」结束；支持「撤销上一点」，不会再一直跟着鼠标。

### 水域/绿地误操作
- 绘制过程**自动存草稿**（每个点都存），刷新/误关页面可恢复；
- `Ctrl+Z` 在绘制中 = 撤销上一个点；
- 底部有「撤销上一点 / 取消 / 完成」；
- 水面填充透明度降到 22%，底图看得见；
- 完成后可 `Ctrl+Z` 或 ↶ 撤销整块水域。

### 建筑
- 模型库已清洗：小凹坑/商铺文字造成的缺口会被修平（保留 L 形）；
- **整理建筑**按钮：把已摆放的建筑也做一次修平；
- **自定义建筑**：工具栏「自定义建筑」→ 依次点轮廓 → 双击/Enter 完成 → 输入名称；可做底图没提取到的特殊形状。

### 手机
- 工具栏自动换行；建筑模型库变成右侧抽屉，点「面板」展开；
- 触摸拖拽/缩放/画点都走 PointerEvent；
- 底部画图条按钮加大。

## 建议流程
1. 导出 → 手机导入；
2. 点「一键整理路网」先接端点、拿路名；
3. 对照蓝色参考路网补缺路/改名；
4. 用「整理建筑」修一次已摆建筑；
5. 导出 JSON 发我，我转 2.5D。
