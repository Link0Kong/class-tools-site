### 0.1 数据结构

- `buildings_trace.json`：`master_size`[w,h]；`model_to_master` 2x3 仿射；`anchors[]`{label,old_ids,model_point,master_point,resid_px}；`residual`{mean,median,p95,max}；`buildings[]` 每项 {id,n,no,k,g,points[[x,y],...],cx,cy,confidence}。
- `features_trace.json`：`master_size`；water[] / island[] / lawn[] / plaza[] / track[]，每项 {area, points[[x,y],...], cx?, cy?}（water/island/lawn 只有 area+points）。

## 1. 坐标系与比例

- 输出全部为 **master 像素坐标**（左上角原点，x 右，y 下），`master_size = [2957, 3463]`。
- `preview_data.json` 为 848x493 的规划示意图坐标：图幅**北向约朝右上 40–55°**，楼栋多边形是**翼/屋顶级**（一个复合楼拆成 2–5 个多边形）。
- 拼接图内部并不完全同源：north 图按 1.0 放置，south ×0.9957，west ×0.8778（west 被重采样，比其它两块细 12.3%），north 图地面底色 `#eff3f6`，south/west 地面 `#e6f0f9`。分割按颜色分别处理，不受影响。
- AMap 图上没有可直接读取的米制比例尺校准；`equivalent_scale = 4.9146 master px / model unit`（旧模型单位≠米）。

## 2. 颜色分割方法

实现：`_work2/r20_extract2.py`（OpenCV 5.0 / numpy），全部按 RGB 精确色/近邻色阈值 + 形态学 + 连通域 + `findContours` + `approxPolyDP`。

| 类别 | 判据 | 后处理 |
|---|---|---|
| 建筑 | RGB 与 AMap 建筑填充 `#d9e3ec`(217,227,236) 的 L∞ 距离 ≤ 10 | 3x3 开运算去 1–2px 细线；`RETR_EXTERNAL` 外轮廓（文字/POI 图标形成的洞自动忽略）；过滤 area<900、minRect 短边<8、solidity<0.35 |
| 水面 | B≥200、R≤190、G≥185、B−R≥45、B−G≥12（含 `#83dcfa` 及其抗锯齿变体）| 3x3 开 + 7x7 闭；`RETR_CCOMP`：外层=水体，内部孔洞且面积>4000=岛 |
| 绿地 | G≥185、G−B≥30、G−R≥25（含 `#aee999` 及草地/树冠变体）| 3x3 开 + 7x7 闭；面积≥4000，solidity≥0.10 |
| 运动场 | 本 AMap 样式未给田径场独立底色，拼接图内也**没有**田径场 | track=[]（见 §8）|
| 广场 | 本 AMap 样式广场与地面/道路同色，无法按颜色分割 | plaza 仅含被灰色分割出的停车场/铺装结构 |

建筑轮廓简化 `approxPolyDP(eps=2.0px)`，水/绿地 `eps=3.0px`；L 形/U 形靠外轮廓保留（不做 bbox）；**注意**：单环 polygon 无法表达内天井，中庭/内院会被填实（图幅内主要是图书馆、厚德楼等内院）。

分割统计：建筑像素（3x3 开运算后）1236662，连通域 **111** 个；按旧红线 `S01` 投影（缓冲 40px）裁剪后 **53** 个在校园内，其中 4 个被判为停车场/铺装（长条停车棚等），最终输出建筑 **49** 个。

### 3.2 最小二乘仿射（6 自由度，含旋转/缩放/剪切）

```
p_master_x = 2.941624 * x + 4.090084 * y -1059.883960
p_master_y = -3.912116 * x + 2.771541 * y +2481.386268

model_to_master = [[2.941624, 4.090084, -1059.883960], [-3.912116, 2.771541, 2481.386268]]
```

残差统计（14 个锚点，master px）：**mean 34.30 / median 32.30 / p95 54.72 / max 59.34**；等价均匀尺度 4.9146，旋转 -53.06°。

残差来源（已核对）：① 旧数据来自总体规划示意图，与实际建成布局存在系统性偏差；② 旧模型楼栋是“翼级”多边形，标签落在复合楼整体中心附近，两者天然有 20–60px 偏移；③ AMap 标签是 POI 标注点，不一定落在建筑几何中心。
另外用 old-model 楼栋轮廓对 master 建筑掩膜做过 chamfer/ICP 校验（平均轮廓距离 6.8px，`_work2/chamfer_fit.json`），与锚点仿射结果一致（~2–3% 差异），可作为交叉验证。

## 4. 建筑匹配方法

步骤（`_work2/r23_final2.py`）：

1. **单元划分**：旧数据里同一复合楼的多个翼（如 `B20–B23 厚德楼`、`B32–B35 五行楼`）先合并为 43 个“匹配单元”（11 个复合组 + 32 个单栋），避免整个复合楼和一个翼比面积。
2. **标签匹配**：25 个已读 AMap 标签中 14 个能对上旧建筑，直接把“标签所在/最近的建筑连通域” 判给对应单元，confidence 0.86（图标在轮廓内时 0.94，如求真楼）。
3. **几何匹配**：其余校园内连通域与其余单元做匈牙利指派，代价 = 中心距离 + 180×(1−IoU覆盖) + 70×|ln(面积比)|， 硬门槛：中心距离 ≤230px、面积比（连通域面积 ÷ 旧组面积·scale²）∈[0.3,3.2]、覆盖 >0.1； confidence = exp(−d/90)·(0.25+0.75·coverage)·min(1, 面积比, 1/面积比)，**<0.20 判 generic**。
4. **名师苑补充**：标签只覆盖 1 栋，另外把岛上 190px 内、面积比合理的 2 个未匹配轮廓补为 B81/B82（confidence 0.55）。
5. 复合楼只有一个连通域时输出组 head id（B20/B24/…）；多连通域时按最近翼分配不重复 id。

## 8. 已知问题与限制（如实）

1. **田径场缺失**：三张原图拼接范围覆盖校园主体 + 北侧公园，但**没有田径场/看台**。旧模型 `T01/T02/B70/B71/B72` 变换后落到 master (155–690, 880–1560) 的空白停车/荒地（见 `_work2/selfchk_north.png` 左侧），该地块在 AMap 上未绘运动场。新布局若需要田径场，只能沿用旧模型投影或补截一张更西/更高 zoom 的 AMap 图。
2. **广场无法按色提取**：AMap 本样式广场、道路、地面同为 `#e6f0f9/#faf8f6`，没有独立填充。plaza 只包含灰色停车/铺装结构；需要的广场（棋盘广场、青年广场、厚德楼前广场等）建议后续手描或用旧数据 G02/G03 投影。
3. **规划示意图 vs 实景差异**：旧数据是总体规划设计图（北向约右上 40–55°），不是实景测量图；`B01–B03`(22#/23#A/B)、`B44–B47`(综合楼)、`B86/B87`、田径场等与现状无法对应；锚点残差 mean 34px 也主要来自这类系统性差异。
4. **宿舍编号体系不一致**：旧数据为 `8#/9#/10#/11#/12# + 学生公寓×7`，AMap 现状为 `11–21 号楼`。`B05–B16` 的 9 个匹配是按位置/面积做的（confidence 0.20–0.81），**编号含义不可靠**；新布局若要显示“11 号楼/21 号楼”等现状名，需要另行按 AMap 文字标签校正。
5. **低置信几何匹配**：B52 河洛时光 0.43、B53 食堂 0.38、B58 培训中心 0.36、B56 后勤配套 0.24 等为邻近位置匹配，其中 B58↔AMap“成人教育学院”楼、B56 的具体归属存在不确定性；使用前建议按 confidence 过滤（≥0.5 可视为可靠）。
6. **园区外结构**：由于旧校园红线 `S01` 是多边形近似投影（缓冲 40px），少量校园外结构（北侧联心村一带 3 栋、东北百氏大厦旁 1 栋、西侧 1 栋）也进入了输出（均为 generic），如不需要可在渲染端按坐标裁掉。
7. **内院被填实**：单环 polygon 无法表达孔洞（图书馆、厚德楼等中庭），如需精确轮廓需改为多环 polygon。
8. **west 图重采样**：拼接时 west 图被缩放到 87.8%，该区域建筑轮廓边缘有 1px 级抖动；建筑整体形状不受影响。

## 9. 使用说明 / 下游建议

- 渲染多边形：直接取 `buildings_trace.json.buildings[].points`（master px），按 `[w,h]=master_size` 做视口变换；`id/n/no/k/g` 可直接做标签和配色（`g` 分组：residential/academic/civic/sports/landscape）。
- 只有 `id != null` 的建筑有旧数据身份；`g="generic"` 的需要新 ID。
- 若要做 3D/体块，可用旧数据 `h/fl` 通过 `id` 关联 `preview_data.json` 的 `buildings` 表。
- 水系/绿地多边形是单环外轮廓（面积已给出），可直接用 `features_trace.json.water/lawn/island`。
- 中间脚本（`_work2/r00–r24*.py`）可复现全部结果；调试图含 `d_full_overlay.png`、`mask_vis1.png` 等。
