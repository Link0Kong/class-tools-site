## 2. 配准方法

三张图均为 AMap 同一底图、同一风格、**北向上**，仅缩放/平移动不同。因此：

1. 以 **SIFT**（`nfeatures=12000–30000, contrastThreshold≈0.02`）+ 比值检验（0.78）做特征匹配；
2. 用 **RANSAC 相似变换（estimateAffinePartial2D）** 剔除误匹配；
3. 最后以 inlier 点对做**轴对齐最小二乘**（只求解统一比例 s 与平移 tx,ty，强制 rotation=0），保证母图严格北向上、无插值旋转；
4. `amap_north` 与 `amap_west` 无重叠（北图底边 y=1571 < 西图顶点换算后 y≈2150），故用 **west → south → north 链式复合** 得到 west→north。

母图坐标 `p_master = p_north + (137, 0)`；以下为"源图 → master"。
