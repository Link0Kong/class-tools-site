本地演示文件 · 非线上版本

数据来源建筑轮廓与高度：「旗山校园 · 三维空间研究」重建数据（已获授权使用）；地名与楼栋号：参照 「福中医（旗山校区）地图」（河洛易班） 校对；校园总平面图：由班级提供。

这是什么用原生 Canvas 2D 绘制的 2.5D 体块校园：拖拽旋转、滚轮缩放、右键平移、点击楼栋查看信息。没有使用 WebGL / Three.js / 任何第三方库，可双击直接打开。

注意建筑高度为建模假设；平面位置按来源图描摹，非比例尺、非测绘成果，不能作为导航依据。教室号规则：01203 = 01 号楼 2 层 03 教室。

贴地与高度所有体块落在统一基座上，建筑脚下有裙边与接触阴影；高度仍为建模假设。

标注说明1–8 号楼 / 33 号楼按手绘图改为「名称 + 楼栋号」；宿舍楼按手绘图顺序标了 22、23A/B、8、9、10、11、12 号楼，其余先以「学生公寓区（11–23 号楼）」归组。

导航说明起点可选「正大门 / 东侧门 / 宿舍区」，也可点卡片里的「此楼出发」把任意楼设为起点，再点另一栋楼即可规划路线。

道路导航按参考站道路中心线计算最短路；道路名依据公开地图截图整理（近似）。它不是真实导航，只用于「从校门/宿舍到某栋楼大概怎么走」。
